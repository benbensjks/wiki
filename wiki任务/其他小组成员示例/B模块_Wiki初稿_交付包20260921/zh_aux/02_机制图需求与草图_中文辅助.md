## 1. Figure 3-1 — 状态依赖的开关（机制图）

### 1.1 要让读者看懂什么

一句话：

> **单比特为什么能记住 0/1：DNA 承载状态，RDF 池承载下一次翻转的方向；
> 每个时钟脉冲到达时，池量决定哪个反应胜出。**

两个必须传达的设计结论：

1. **一次脉冲一次翻转**成立的条件是 **RDF 积累延迟 > Int 脉冲宽度**，否则同一脉冲内来回双翻；
2. **BM3R1 的作用是延迟而非"越强越好"**：PB 态压制 RDF 产生，翻转后消退，RDF 才得以积累。

### 1.2 构图

左右两张状态卡 + 两条脉冲弧线：

- **PB 卡（左）**：DNA 图标 `attP × attB`；BM3R1 表达（由 DNA 引出箭头）并阻遏 RDF 基因
  （T 形端点）；RDF 池量条近乎空；注"池在脉冲之间被清空"。
- **LR 卡（右）**：DNA 图标 `attL × attR`；BM3R1 灰化（"翻转后消退"）；RDF 基因去阻遏
  （由 DNA 引出箭头）；池量条近乎满；注"池在 LR 驻留期累积"。
- **上弧（PB → LR）**：标注 `clock pulse 1: free Int drives forward recombination`；
  **下弧（LR → PB）**：标注 `clock pulse 2: Int–RDF complex drives reverse recombination`；
  每条标注前加一个小方波脉冲图标。
- **页脚规则**："Memory = the RDF pool: ≈4.5 µM (LR) vs ≈0.002 µM (PB) at pulse arrival,
  ≈2500× contrast" 与 "Constraint: RDF delay > pulse width"。

### 1.3 禁止画错的点

1. **记忆在 RDF 池，不在 Int**；Int 是每个脉冲来一次的"读/写头"；
2. **反向重组由 Int–RDF 复合物驱动**，不是游离 Int 或游离 RDF 单独驱动；
3. **状态依赖的生产方向不能反**：PB → BM3R1 ON / RDF OFF；LR → BM3R1 OFF（消退）/ RDF ON；
4. **池量是机制本身**：脉冲到达时 PB 近空、LR 近满；
5. **不要把 RDF 画成抑制剂**（如抑制或降解 Int）——它是与 Int 形成复合物的方向性因子。

### 1.4 可直接使用的英文标签

见英文主稿 §1.4（同一套标签）。

### 1.5 图注草稿

> **Figure 3-1. 状态依赖的开关（概念草图）。**
> DNA 元件有 PB / LR 两种构型。PB 态下 BM3R1 表达并阻遏 RDF 产生，脉冲到达时 RDF 池近乎空
> （≈0.002 µM），因此时钟脉冲驱动正向反应（PB→LR）；LR 态下 BM3R1 消退、RDF 累积
> （脉冲到达时 ≈4.5 µM，约 2500× 对比），下一个脉冲形成 Int–RDF 复合物驱动反向反应（LR→PB）。
> 记忆寄存在 RDF 池；延迟必须盖过脉冲宽度。

## 2. Figure 3-2 — 设计窗口与失效模式（概念图）

### 2.1 要让读者看懂什么

> **窗口为什么有边**：每一侧各因一个明确的机制失效；窗口是 tag 速率与表达比例的联合属性，
> 不是单个安全数值。

### 2.2 构图

两个面板：

- **A 面板 — tag 窗口**：横条三段（太弱 / 确定性通过 [3, 24] h⁻¹（含随机全稳子带 [6, 18]）/
  太强）；下方三条示意 $S(t)$ 迷你轨迹与注解（间隙 Int → 多翻 / 一脉冲一翻 / 峰削 → 卡 LR）。
- **B 面板 — 联合表达窗口**：示意 $(\beta_R,\beta_B)$ 平面上的绿色通过平台
  （β_R 4–8 × β_B 0.75–6，实测）；各侧失效标注（RDF 太弱 → 回翻不完整；RDF 太强 →
  泄漏放大 → 自发翻转；BM3R1 太弱 → 池未清空 → 多翻）；上方虚线框"超出已测范围"；
  虚线箭头"泄漏越高，窗口越向低 RDF 强度收缩"。

### 2.3 禁止画错的点

1. 本图为**示意版**；实测通过/失败图是可行域数据图（Figure 3-4B），不得混称；
2. 窗口数字：确定性 **[3, 24] h⁻¹**、随机全稳 **[6, 18] h⁻¹**；平台 **β_R 4–8 × β_B 0.75–6**；
3. 失效机制与侧别不能错（弱 tag → 多翻；强 tag → 卡 LR；弱 RDF → 回翻不完整；
   强 RDF → 泄漏放大）；
4. 泄漏箭头方向：泄漏升高 → 窗口向**更低** RDF 强度移动。

### 2.4 图注草稿

> **Figure 3-2. 设计窗口与失效模式（概念草图）。**
> （A）Int 降解标签窗口的两侧：太弱 → 间隙 Int 残留 → 多翻；太强 → 脉冲峰被削 → 回翻失败
> （卡在 LR）；确定性通过带 [3, 24] h⁻¹、随机全稳带 [6, 18] h⁻¹。
> （B）联合表达窗口是一个平台（非零泄漏方案实测：β_R 4–8 × β_B 0.75–6）；各侧失效机制不同，
> 泄漏升高使窗口向低 RDF 强度移动。示意版；实测通过/失败图见可行域数据图。
