## 2. 第一部分：单 Bit 的拓扑动力学与参数分析 (Single-Bit Topological Dynamics)

> **目标**：阐明二进制 0/1 状态的 DNA 拓扑转换机制，建立完整 ODE 数学模型并进行参数生物学含义标定。

### 2.1 拓扑重组与开关机制

- **0 与 1 的拓扑定义**：PB 状态 (`attP × attB`, Bit 0) 与 LR 状态 (`attL × attR`, Bit 1)。
- **正向翻转（0 → 1）**：

  - 整合酶二聚体 `Int₂` 的结合与联会 (`PB → PB-intₛ`)。
  - 链交换与热力学构象修饰 (`mod`)：由低自由能突触异构体 `LR-intₛ₂` 锁定 LR 拓扑。
- **逆向复位（1 → 0）**：

  - 重组方向性因子 (RDF, gp3) 与 `Int₂` 形成四聚体异构复合物 `Int₂-RDF₂`。
  - 逆向联会与复位链交换过程。

### 2.2 BM3R1 时间延迟调控网络

- **启动子方向性控制**：处于 PB 态时驱动阻遏蛋白 `BM3R1` 表达；处于 LR 态时驱动报告基因与 RDF 表达。
- **延迟关断逻辑**：当 DNA 翻转为 LR 态后，残余 `BM3R1` 逐步稀释/降解，对 `P_bm3r1` 的 Hill 深度抑制解脱，触发 RDF 延迟积累。

### 2.3 数学模型与 ODE 方程组

- **蛋白表达与降解方程**：`Int` 脉冲驱动、`BM3R1` 积累、`RDF` 的 Hill 抑制表达。
- **DNA 拓扑重组速率方程**：包含竞争性抑制项的 `v_fwd` 与复合体驱动的 `v_rev`。

### 2.4 参数含义与敏感性表格

- 整理 13 个关键生物学参数（如 `k_int`、`γ_int`、`α_bm3`、`K_inh`、`K_D,comp` 等）的推荐数值、物理/生物学单位与阈值意义。

### 2.5 仿真结果与风险提示 (Figure 1 剖析)

- **波形分析**：结合单 Bit 拓扑翻转轨迹，分析三次输入脉冲下的 `PB/LR` 切回过程。
- **实验组注意项 (毒性预警)**：为了保证逆向翻转彻底，系统需要很高的 RDF 浓度，需评估高浓度 RDF 是否存在宿主细胞毒性。

## 3. 第二部分：完整二级级联的机制与原理 (Level-2 Carry Cascade)

> **目标**：介绍基于非相干前馈环 (I1-FFL) 的脉冲进位机制，展现 Bit 0 到 Bit 1 的单次精准触发过程。

### 3.1 I1-FFL 脉冲生成逻辑

- **进位触发条件**：当 Bit `i` 完成 `LR → PB`（复位归零）时，恢复组成型启动子表达激活因子 `Aᵢ`。
- **双分支时序差**：

  - **快速分支 (Direct Activation)**：`Aᵢ` 迅速拉高下一级整合酶 `Intᵢ₊₁` 的转录。
  - **慢速分支 (Delayed Repression)**：`Aᵢ` 延迟激活阻遏因子 `Rᵢ`，随着 `Rᵢ` 超过阈值后关断 `Intᵢ₊₁`。
- **脉冲形成**：挤出一个有限宽度的窄脉冲 `Intᵢ₊₁`，确保下一级仅精准翻转一次。

### 3.2 振荡器驱动与二级计数 ODE 方程

- **驱动源输入**：Repressilator 驱动产生 `Int₀` 脉冲信号。
- **级联方程表达**：

  - 激活因子 `A₀` 与阻遏因子 `R₀` 动态方程。
  - AND 逻辑门控下的 `Int₁` 脉冲生成方程：`f_A(A₀) × g_R(R₀)`。

### 3.3 二级级联仿真结果与三子图拆解

- **Panel 1 (Bit State)**：Bit 1 发生 `LR → PB` 触发，Bit 2 接收进位信号完成单次翻转。
- **Panel 2 (Concentration)**：`A₀` 快速上升与 `R₀` 缓升的时间差，表现明显的时间延迟效应。
- **Panel 3 (Int Level)**：生成的非对称 `Int₁` 窄脉冲（上升沿由 `A₀` 主导，下降沿由 `R₀` 关断）。

## 4. 第三部分：理想化三级级联与泄漏抑制优化 (Idealized Level-3 Cascade)

> **目标**：展开 3-Bit 逻辑计数器模型，揭示静态等待期的“提前泄漏”问题，提出具体优化方案并展示完整 P1–P8 计数波形。

### 4.1 三级级联拓扑架构与二进制递增逻辑

- **级联链路**：`Bit 0 →(Int₁)→ Bit 1 →(Int₂)→ Bit 2`。
- **二进制状态映射**：P1 `(0, 0, 1) = 1` → … → P7 `(1, 1, 1) = 7` → P8 `(0, 0, 0) = 0` 循环。

### 4.2 核心瓶颈：静态等待期的提前泄漏 (Early Leakage) 及优化方案设计

- **问题现象**：在 P2/P3 等静态等待阶段，上游高稳态表达导致 `Int₂` 出现底噪积累，引发 Bit 2 提前触发翻转或 Bit 1 非预期回退。

- **方案 A：`A₁` 蛋白负自馈调控 (Negative Autoregulation)**

  - **机制**：将 `A₁` 启动子改造为负反馈启动子。
  - **效果**：压缩稳态浓度，生成陡峭瞬态脉冲后迅速压低驱动力，削弱静态期泄漏。
