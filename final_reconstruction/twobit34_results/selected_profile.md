# 正式选定参数配置

联合扫描和独立复核后，正式参数中心选为：

```text
uM_per_au = 5.75
bit mRNA half-life = 2 min
bit maturation half-life = 20 min
kon = 0.1 /(a.u. h)
koff = 1 /h
complex decay = 1 /h

carry mRNA half-life = 2 min
A0/F0 maturation half-life = 32.5 min
add_growth = False
```

选择理由：它不在三个扫描轴的任一边界上，六个轴向邻居全部通过完整因果认证；在两个严格内部点中，它的最小时间裕量更大。

| 候选 | 严格六邻域内部 | 冷启动 | 最小裕量/h |
|---|:---:|:---:|---:|
| **5.75 / 32.5 / 2** | 是 | 通过 | **2.914** |
| 5.75 / 30 / 2 | 是 | 通过 | 2.705 |
| 6.00 / 32.5 / 2 | 否；6.25方向邻居失败 | 通过 | 3.003 |
| 6.00 / 30 / 2 | 否；6.25方向邻居失败 | 通过 | 2.799 |

`6.5/35/*` 等网格角点有更大时间裕量，但无法判断网格外侧是否继续通过，因此不选作正式中心。

四种轨道自洽初态 `00/01/10/11` 已在本中心分别续跑300 h，全部严格按模4计数并通过完整因果认证，结果位于 `initial_states_selected/`。

## 已确认的参数语义

- 曾墨涵确认 γ 是“本征降解 + 生长稀释”的总清除率，因此 `add_growth=False` 是正确实现；
- `add_growth=True` 会重复加入稀释，只保留作历史诊断，不能作为物理候选；
- `k_int=6` 是方波输入专用调参量，只为得到正常Int0脉冲，不应乘到真实C31通量上。

## 尚未闭合的生长条件

韩亚轩上游使用50 min倍增时间，即 `mu≈0.8318/h`；曾表最小总清除率为 `0.6/h`。如果两者属于同一细胞条件，则总清除率不能小于稀释率，因此不自洽。

当前做法是保留两位作者各自给出的数值，不擅自重算；需要继续询问曾墨涵当时采用的稀释率或倍增时间。在得到该数值前，应把上下游视为来自不同或未对齐的生长条件。
