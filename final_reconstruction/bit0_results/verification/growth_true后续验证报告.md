# `add_growth=True` 工作区后续验证报告

> **解释更新（2026-09-20）**：曾墨涵已确认表中gamma包含生长稀释。因此这里的 `add_growth=True` 会重复加入稀释，本报告证明的是一个数学诊断区域，不再把它列为物理候选。正式模型应使用 `add_growth=False`。

## 结论

原 800 点重扫发现的 `add_growth=True` bit0 工作区是真实、数值收敛且具有有限参数宽度的周期二分频解，不是孤立数值伪影。其宇称可由两个真实周期轨道分支长期保存，中途翻转 DNA 状态也会永久改变宇称。

但是，这个工作区不能驱动曾墨涵表内参数不变的 A0/F0→bit1 接口。直接 A0/F0、共同成熟延迟以及激活臂/抑制臂分别成熟的 34 个组合均失败。最佳组合的 bit1 最高仅到 0.549，不能形成稳定第二位。因此它目前是可信的**单 bit0 方案**，不是可用的两比特级联方案。

## 1. 严格数值收敛

复核了 8 个代表点：4 个 `growth=True` 通过点、2 个相邻失败点、2 个 `growth=False` 通过点。每点均比较：

- `max_step=4 min, rtol=2e-7, atol=2e-9`；
- `max_step=2 min`；
- `max_step=1 min`；
- `max_step=1 min, rtol=1e-9, atol=1e-11`。

8/8 的完整码串和通过/失败结论一致；相对严格参考，S极值和驻留分位数的最大差为 `7.2e-10`。因此原 800 点中新发现的 `growth=True` 通过点不是步长或容差伪影。

## 2. 局部工作区

固定 `add_growth=True`，扫描：

- `uM_per_au = 0.6, 0.8, 1.0, 1.2, 1.4`；
- bit成熟半衰期 `6, 8, 10, 12, 14 min`；
- 原网格中通过的6组 `kon/koff`。

150点中35点通过稳态有限读窗判据，全部通过点最低 commitment 为1.0。通过区形成斜带：换算较低时需要较长成熟时间，并非 `uM=1,t_mat=10 min` 的孤立点。

| uM | 各成熟时间6/8/10/12/14 min的通过数（每格6点） |
|---:|---|
| 0.6 | 0 / 0 / 0 / 2 / 3 |
| 0.8 | 0 / 1 / 3 / 5 / 6 |
| 1.0 | 0 / 3 / 6 / 2 / 0 |
| 1.2 | 3 / 1 / 0 / 0 / 0 |
| 1.4 | 0 / 0 / 0 / 0 / 0 |

对两个中心补扫完整4×4复合物动力学矩阵：

- `uM=0.8,t_mat=14 min`：7/16通过；
- `uM=1.0,t_mat=10 min`：6/16通过。

推荐的 bit0 局部中心为 `uM=0.8,t_mat=14 min,kon=1,koff=3,add_growth=True`。它位于多个相邻通过组合内部，而非单一边界点。

## 3. 生化机制与宇称

推荐点连续400 h的drop4码串严格交替，33个读窗全部有效，最低 commitment=1.0；有限读窗中位电平约0.234/0.745。

从稳定周期-2轨道的两个相邻、相反分支取完整生化状态，并将上游重置为相同相位后续跑180 h：

- 分支A：`010101...`；
- 分支B：`101010...`；
- 两者始终反相，末40 h最大差0.775。

在100 h将S强制翻转后继续到400 h，末6周期仍与参考轨迹完全反相，说明宇称改变能够长期保存。

手工构造的准稳态高/低初值会收敛到同一轨道分支；这说明那组人工初值落在同一吸引盆，不能替代从真实周期轨道构造自洽分支的检验。

这个区域的方向选择没有原 `growth=False,uM=6–10` 工作点干净：

| 跃迁 | ∫正向 | ∫反向 | ∫重叠 | 重叠/较小通量 |
|---|---:|---:|---:|---:|
| 0→1 | 2.44 | 1.93 | 1.17 | 61% |
| 1→0 | 1.97 | 2.48 | 1.28 | 65% |

方向仍由净通量决定，但同时双向重组很强，说明它是更依赖通量抵消的工作区，物理裕量不如原候选清楚。

## 4. A0/F0→bit1 接口

两个稳健中心接入表内参数不变的I1-FFL后：

| bit0点 | A0/F0实现 | g0峰值 | Int1源峰值 | 两比特结果 |
|---|---|---:|---:|---|
| uM=0.8,tmat=14,kon=1,koff=3 | 直接成熟蛋白 | 0.0407 | 0.732 | 失败 |
| 同上 | A/F共同30 min成熟 | 0.00964 | 0.173 | 失败 |
| uM=1,tmat=10,kon=1,koff=3 | 直接成熟蛋白 | 0.0289 | 0.520 | 失败 |
| 同上 | A/F共同30 min成熟 | 0.00822 | 0.148 | 失败 |

最高驻留点 `uM=0.8,tmat=14,kon=1,koff=1` 的直接门峰值可到0.0562，但bit1仍只到约0.548。

进一步扫描A0成熟2/5/10/20 min、F0成熟10/20/30/45/60 min，并只保留F0比A0慢的34组：

- 稳态两比特通过：0/34；
- 完整认证：0/34；
- 最大 `g0=0.0581`；
- 最大 `S1=0.549`。

较慢F0不能救回接口：预平衡F0池跨周期残留，使抑制臂释放更慢，周期性carry峰反而下降。

## 5. 路线选择

在“不修改曾墨涵表内I1-FFL强度和阈值”的约束下：

1. `growth=True` 路线只作为重复稀释的数学诊断保留，不能作为物理单bit候选；
2. 当前唯一通过完整两比特因果认证的路线仍是 `uM=6,add_growth=False` 加A0/F0显式表达层，carry成熟半衰期25–35 min、标称30 min；
3. 曾墨涵已确认gamma包含稀释，因此 `add_growth=False` 不再是条件性猜测；
4. 仍需取得她采用的具体mu/倍增时间，解决与韩亚轩50 min倍增条件的数值不一致；
5. 在gamma解释和两比特路线未定稿前，不接bit2。
