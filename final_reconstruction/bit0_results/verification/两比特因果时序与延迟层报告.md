# 两比特因果时序与延迟层报告

## 结论

原 `uM_per_au=6` 两比特轨迹在有限读出窗口内可以给出正确的模 4 序列，但未通过严格因果顺序：bit1 的阈值翻转比 bit0 主要反向重组事件开始早约 0.73–1.55 h。扫描 `uM_per_au=5.5–7.5` 没有找到同时满足读出、事件一一对应和严格先后顺序的基线工作点。因此只调 a.u.–µM 换算不能修复接口。

把 A0/F0 的直接成熟蛋白生成替换为显式的 `mRNA -> 未成熟蛋白 -> 成熟蛋白` 表达链后，在不修改任何 `ZENG` 数值的前提下找到了通过区。`uM_per_au=6`、carry mRNA 半衰期 2 min、carry 成熟半衰期 25–35 min 时，300 h 冷启动和稳态均通过，读出序列为：

```text
123012301230123012301230
```

建议暂取 30 min 为标称值。该点 bit1 相对主要反向重组起点的延迟为 0.47–1.11 h，最小读出建立裕量 4.43 h，最小保持裕量 2.80 h。

把已稳定的韩亚轩上游分别平移 0、2、4、6、8、10 h，同时将全部下游状态重置为相同 PB 初态后，六组 300 h 仿真全部通过冷启动、稳态、事件一一对应和因果顺序。因此标称点不是由唯一上游初相位偶然造成。

## 统一验收方法

验证器为 `verify_twobit_causal.py`，不使用单一时刻的 0.5 阈值作为唯一成功判据。

1. 以 bit0 的实际反向重组通量 `J_rev0` 定义 LR→PB 物理事件；绝对事件阈值为 0.10/h。
2. carry 门必须达到绝对活性 `g0>=0.05`，持续至少 0.2 h，且门剂量至少 0.02 h；不再把任意小波纹按相对峰高计作 carry。
3. 每个主要 `J_rev0` 事件必须一一对应一个 carry 门事件和一次 bit1 翻转，不得有额外事件。
4. carry 开始和 bit1 翻转均必须晚于主要反向重组事件开始，允许一个 2 min 采样步长的数值容差。
5. 数字读出使用真实时钟通量谷附近、占一个周期 20% 的有限窗口；bit0/bit1 均要求至少 80% 的窗口时间处于 `S<=0.3` 或 `S>=0.7`。
6. 冷启动和丢弃前 4 个读点后的稳态分别报告。

这些绝对阈值是工程验收标准，不是实验拟合参数；原始峰值、剂量、时延和完整事件表均保存在 JSON 中，便于改变标准后重判。

## 显式 A0/F0 表达延迟

`verify_carry_delay.py` 在两比特 30 状态之外临时追加 `M_A0, A0_u, M_F0, F0_u` 四个状态，A0/F0 成熟蛋白仍保留原位置。每个 bit 内部仍严格保持原 11 状态。新增状态及其半衰期属于明确标注的接口假设，当前尚未合并进基线 `model.py`。

| 成熟半衰期/min | 冷启动 | 稳态 | 因果顺序 | 认证 | 解释 |
|---:|:---:|:---:|:---:|:---:|---|
| 10–20 | 否 | 否 | 否 | 否 | 延迟不足，仍提前翻转并逐渐失锁 |
| 25–35 | 是 | 是 | 是 | 是 | 完整冷启动通过区 |
| 40–42.5 | 否 | 否 | 是 | 否 | 时序顺序正确，但启动读窗落入过渡带 |
| 45–55 | 否 | 是 | 是 | 是（稳态） | 需丢弃较长启动段 |
| >=60 | 否 | 否 | 否 | 否 | 延迟过大，漏 carry 或 bit1 粘滞 |

25–35 min 各点的读出窗口最小 commitment 均为 1.0。标称 30 min 位于冷启动通过区内部，避免选择仅有稳态通过的 45–55 min 区域。

## 尚未闭合的问题

1. 曾墨涵已确认表中 gamma 是“本征降解+生长稀释”的总清除率，因此 `add_growth=False` 的结构处理正确；待补的是她采用的具体稀释率/倍增时间。韩亚轩上游 `mu≈0.8318/h` 大于曾表最小gamma 0.6/h，两者尚不能解释为同一生长条件。
2. 新增的 carry mRNA/成熟参数没有实验标定；25–35 min 是模型要求的工程窗口，不是已测生化常数。
3. 上游 0–10 h 相位平移已通过；尚未做自洽高/低初态和 carry 延迟参数联合扰动验证。
4. bit2 仍不应接入；应先完成上述鲁棒性验证，并确认延迟层是否作为最终模型的一部分。
