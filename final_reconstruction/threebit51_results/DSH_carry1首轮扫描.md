# dsh：51状态第二级carry首轮扫描

等当前34状态扰动与严格容差任务完成后再运行。本扫描不得修改冻结34状态文件、ZENG或51状态源文件。

## 网格

```text
carry1 mRNA半衰期 = 0.5, 1, 2, 4, 8 min
A1/F1共同成熟半衰期 = 5, 10, 20, 30, 40, 50, 60 min
```

共35点，每点600 h。只改变A1/F1新增表达参数；前34状态、uM、bit内部参数和门 `K=0.4,n=3` 均冻结。

## 运行

7个独立进程，每片5点：

```powershell
python scan_threebit51_carry1.py scan --shard <0..6> --nshards 7 --hours 600
python scan_threebit51_carry1.py merge --nshards 7
```

如 `Wait-Process` 被拒绝，继续使用“CSV达到5行且meta JSON出现”的文件系统完成检测。

## 汇总要求

1. 35/35完整性、积分失败和非有限轨迹；
2. 完整模8认证点数量；
3. 每点bit1反向事件数、g1窗口数、bit2穿越数；
4. off/on门峰值比，阈值为0.10；
5. 若无认证点，按“bit2穿越数最接近bit1反向事件数”排序前10；
6. 判断共同成熟时间是否足以解决反向翻转不足；
7. 若仍无解，再建议A1/F1分开成熟网格，不得提前修改ZENG。

扫描器哈希应在启动前记录，并与结束后及各分片环境记录比较。
