## 1. 结论摘要（三句话）

1. **静态容差 = SMALL**：三个旋钮里最差的是 `conc_scale`（全局浓度增益），
   认证区间只有 **[0.95, 1.00]**，对称宽度 **0**；`clock_K` 在整个 ±20 % 网格内**全部认证**；
   `K_A1` 为 −20 %…+5 %。
2. **但 SMALL 的成因不是"计数失效"**：7 个未认证点里 **4 个是 contrast 臂单独失败**
   （`off/on` 门峰值比 > `MAX_OFF_ON_GATE_RATIO = 0.10`），它们的**数字读出完全正确**
   （14/14、序列 `12345670…` 精确、0 个未标定窗）。其中一个（`conc_scale|1.05`）
   配对泄漏 **0.01069 还优于冻结点 0.01422**。
3. **小数字成立**：计数写入由 **~20 个 b2_I 拷贝**执行（门相最小值），F1 全周期谷值 **40 拷贝**，
   对应本征 CV ≈ 22 % / 16 %；显式复合物池在门相的**中位数只有 1.5 个分子**。

**因此**：预登记规则的字面输出（"随机性研究是必需的"）**不可直接引用**，
它把一条已被 H4 降级的指标（off/on 峰值比）当成了判定依据。**真正支持"需要随机性研究"的**
是第 3 条（小数字）与第 2 条里的余量分析（冻结点在该 contrast 臂上只剩 1.83 × 余量），
而不是规则本身。这一点是本次预审**最重要的产出**，也是对我自己预登记的修正。

> 冻结点距离该臂的限值只有 1.83 ×，而 +5 % 的全局增益就会越线（0.1071），
> 与此同时计数器仍然在正确地数。

## 4. 拷贝数盘点（小数字问题）

### 判据修订记录（两次，全部保留在产物里）

- **Rule A（预登记原文）**：对小 pools 的**最小最小值**套阈值 → 命中 `b2_C = 5.1e-9`。
  **退化**：那不是"小数字"，那是"该时刻不存在"。
- **Rule B（看到 run 1 后加）**：改用全周期**中位数**判定存在性，但敏感性计算又把全周期最小值
  折回来 → 得出 b2_I 需要 `uM_per_au` 提高 **9.4e4 ×** 的荒谬数字。
- **Rule C（现行，报告用）**：**拒绝给出单池判定**，改报 per-pool / per-phase 全表 + 每个统计量的
  CV 与"升到 100 拷贝所需 uM_per_au"。**一次会话里两次修订说明"最小池"这个统计量本身是错的工具**，
  不是阈值需要调。Rule A/B 仅作为修订记录保留。
