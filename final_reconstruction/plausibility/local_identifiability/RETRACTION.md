## 1. 已确认的错误：工作点混用

`build_with`（旧版）写成：

```python
ext, carry1, n_gate = frozen_extension(), frozen_carry0(), None
for name, value in overrides.items():
    ...
    elif k == 'ctor':
        n_gate = float(value)      # 只有 n_A1_gate 被扰动时才赋值
```

而 `model_threebit51.py`：

```python
return ZENG['n_A'][1] if self.n_A1_gate is None else float(self.n_A1_gate)
```

`NOMINAL['n_A1_gate'] = 6` 只是一个字典常量，**从未被传进模型构造**。实测复核：

| 运行 | `overrides` | `n_A1_gate_effective` |
|---|---|---:|
| baseline | `{}` | **4.0** |
| `complex_on`、`uM_per_au` 等 8 个参数的 48 次 | 仅该参数 | **4.0** |
| `n_A1_gate` 自身 6 次 | 含 `n_A1_gate` | 6.12 / 5.70 等 |

**49 次在 n=4，6 次在 n≈6。**

后果：拼出的 9 列矩阵**不是同一个参数点上的 Jacobian**，因此它的秩、条件数、
最弱方向、以及任何参数相关系数**全部无效**。

这与我在审核旧 `check_identifiability.py` 时指出的缺陷是同一个——我把同样的错误在
新脚本里又犯了一次。旧脚本的问题（`run_threebit` 不传 `n_A1_gate`，实际跑 n=4）已
记入 `ANALYSIS_STATUS.json`。

## 2. 撤回的结论

以下全部撤回：

1. **"相位伪影是已定位根因"** —— 撤回。固定时刻差分中，翻转时刻变化是
   `∂S/∂p = ∂s/∂p − (∂s/∂t)(∂τ/∂p)` 的第二项，是**真实的时序灵敏度**，不能当伪影删掉。
   σ₁ 随步长缩小上升不足以证明严格的 `1/h` 发散；不同观测集合给出不同相关矩阵是常态；
   去掉 S2 后信息下降也可能是 S2 确实携带独有信息。而且本轮存在已确认的工作点混用，
   必须先排除。正确表述应为：

   > 在当前实现与扰动尺度下未得到可信的局部灵敏度估计；工作点混用是已确认错误，
   > 时序灵敏度与有限幅度非线性是待进一步区分的因素。

   不得据此宣布"局部灵敏度方法在这个系统上不可用"。

2. **"`q·K_D_comp` 精确结构退化"** —— 撤回。`K_complex = q·K_D_comp` 使 q 从反向 Hill
   中约掉，**只在准稳态 `C ≈ q·I·R` 下成立**。模型显式积分 C，因此
   `kon`、`koff`、`complex_decay` 还决定复合物弛豫时间、游离 Int/RDF 的隔离量、
   以及复合物损失。结构不可辨识必须针对完整方程与指定观测模型证明，不能只看阈值的
   定义。（此前已被提醒过一次，我仍重复了该判断。）

3. **"仍然站得住的三条"** —— 全部撤回：
   - `n_A1_gate` 与 `uM_per_au` 不混淆：两列来自不同工作点，无效；即使同点，单对
     相关系数接近零也不能排除多参数联合混淆；
   - `mRNA` 与 `A1` 成熟强负相关：对应的是 n=4 配置，只能降级为待验证线索；
   - `q ↔ K_D` 精确退化：见上。

另外，"有效秩 8" 是人为阈值 `σ/σ_max > 1e-3` 下的有效秩，不是严格数学秩；最小奇异值
非零时不能宣称存在精确退化方向。
