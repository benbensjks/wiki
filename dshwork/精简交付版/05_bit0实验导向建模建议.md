# 实验只做bit0：下一步怎样细化模型

目标是预测真实实验能看到的单比特行为：每个脉冲后有多少DNA／细胞处于0或1、要等多久、能保持多久、下一次脉冲能否正确反向切换。多比特模型保留为系统扩展证据，实验拟合集中在bit0。

## 第一优先：DNA状态与测量输出分开

当前S是连续的LR构型比例，不直接等于某个单细胞内唯一DNA分子的0/1，也不等于荧光强度。

建立一个17状态子系统（6个上游状态＋bit0的11状态），并在其后接实际报告基因的观测模型：

```text
DNA构型 → reporter mRNA → 未成熟荧光蛋白 → 成熟荧光蛋白 → 仪器读数
```

若PB与LR分别对应两个颜色，应分别建立两条报告链；没有双报告构建时，不额外虚构实验读数。报告链先作为无反馈观测层，只有发现资源竞争或滴定证据时再引入反馈。

这样可以区分“DNA没有切换”“DNA切换了但荧光尚未成熟”“旧荧光蛋白仍然残留”。输出至少包括LR比例、预测荧光、翻转延迟、保持时间。

## 第二优先：围绕实验输入，而不是只跑固定周期

分别考察单次输入、两次输入和连续输入；输入可以先按实验实际使用的诱导波形或实测C31轨迹给定，再接完整振荡器。

重点扫描：脉冲强度、持续时间、两脉冲间隔和背景表达。输出两张设计图：

- 脉冲强度×持续时间 → 正向／反向切换完成度；
- 脉冲间隔×RDF恢复水平 → 下一次翻转成功区。

通过比较等剂量但不同峰宽的输入，判断翻转受峰值、总剂量还是恢复时间限制。具体扫描范围由实测输入或组内可实现范围确定，不把当前a.u.范围直接当实验处方。

## 第三优先：从平均比例升级到单细胞翻转分布

若DNA只有一个／少数拷贝，可以让每个拷贝显式处于PB或LR，而不是只用连续S。模型以化学反应概率产生转换；输出为每次脉冲后保持／翻转的概率与等待时间分布。

若为多拷贝质粒，区分PB与LR拷贝数、复制和分裂分配。荧光均值相同可能对应“一半细胞全开”或“每个细胞一半质粒开”，两者在后续计数中的可靠性不同。

初步可用蛋白浓度ODE＋离散DNA状态的混合模型；更完整的SSA需要反应级推进率和分子数量纲，不能把Hill指数6解释为6分子同时结合，也不能直接对当前所有ODE项机械加噪声。

## 第四优先：只在数据需要时细化重组机制

现有Int–RDF复合物是有效状态，并未描述全部DNA结合、联会、交换和产物释放。如果实验出现持续不完全反转、延迟异常或拷贝数依赖，再增加最少的可区分中间态，例如：

```text
可用DNA → 酶结合DNA → 重组中间态 → 产物复合物 → 可再次反应的DNA
```

Pokhilko等的研究以实验重组动力学为依据讨论了方向性与产物复合物，可作为机制扩展参考；具体中间态和参数需要与实际构建匹配，不能直接照搬全部网络。

参考：[ϕC31方向性实验与建模（2016）](https://pmc.ncbi.nlm.nih.gov/articles/PMC5009753/)；[简化方向性模型（2017）](https://pmc.ncbi.nlm.nih.gov/articles/PMC5310728/)。这些是建模组参考链接；网页引用格式由Wiki组决定。

## 标定顺序

先对齐实验生长曲线与总清除率，再校准报告成熟／清除和输入强度；随后拟合单次正向、单次反向曲线，最后用未参与拟合的双脉冲或连续输入检验模型。

有数据支持时再扩充参数。优先回答可测问题，不以状态数越多作为模型更好的标准。旧可辨识性结果尚未通过审核，不能用它宣称参数已经可单独识别。

## 最推荐的下一份交付

**“bit0 DNA–荧光联合预测”**：保留原11状态作为对照，增加真实报告读出层；用单脉冲和双脉冲分别检查切换、保持和恢复，再决定是否需要单细胞离散模型。

需要实验组明确的信息只有：DNA位点位于染色体还是质粒／预期拷贝数、Int与RDF是否融合、实际输入形式、报告基因种类与读出方式、培养条件及生长曲线。当前文件是设计建议，尚未实现或声称获得新的实验拟合结果。
