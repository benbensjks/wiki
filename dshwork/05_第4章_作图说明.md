## 3. Figure 4-1 — 进位模块机制 / I1-FFL carry module

### 构图 / Layout

```text
Previous bit DNA state
        │  (1 - S_n)
        ▼
   Activator A ──────────────┐
        │                     │  ×  (AND)
        └── Expression delay ─┤
                ▼             │
        Repressor F ──────────┤
                              ▼
                    Carry promoter output g
                              │
                              ▼
                    Next-bit integrase pulse
                              │
                              ▼
                    Next bit: S flip

Clock gate ───────────────────┘  (AND)
```

**必须画对的三点**（在图上用小字标注）：

1. `A and F are multiplied (AND), not added`；
2. `F lags A — this is what makes a pulse instead of a plateau`；
3. `All three factors are required: A, F, and the clock gate`。

建议在右侧并列画两个小对比图：**无延迟臂 → 平台**；**有延迟臂 → 窄脉冲**。

### 可直接粘贴的英文

```text
I1-FFL carry module
Previous bit DNA state
PB fraction = 1 - S
Activator A (coherent arm)
Repressor F (incoherent, delayed arm)
Expression delay
Carry promoter output g
Next-bit integrase pulse
Next bit DNA state flip
Clock gate
AND (multiplication)
A and F are multiplied (AND), not added
F lags A - this is what makes a pulse instead of a plateau
All three factors are required: A, F, and the clock gate
Without the delayed arm: plateau
With the delayed arm: narrow pulse
```

### 构图 / Layout

```text
Panel 1  One cycle of g0
         y-axis: log scale
         annotate: max(g_on), max(g_off), L_peak = max(g_off) / max(g_on)

The residual alone is not the risk
Large RDF pool in the next bit

Wrong-direction dose accumulates
Peak contrast alone is not a sufficient acceptance test

```

## 5. Figure 4-3 — 进位因果链 / Carry causality chain

### 构图 / Layout

四行共享时间轴，自上而下：

1. 第 0 位反向重组通量 $J_{rev,0}$；
2. 进位启动子窗口 $g_0$；
3. 第 1 位重组酶的完整表达链响应（mRNA → 未成熟 → 成熟，可画成三个叠加曲线）；
4. 第 1 位 DNA 状态 $S_1$。

在四个环节之间画竖向对齐虚线，并在顶部标注事件链顺序：

```text
J_rev  ->  g window  ->  integrase pulse  ->  S flip
```

### 可直接粘贴的英文

```text
Carry causality chain
Reverse recombination flux of the previous bit
Carry promoter window
Integrase expression chain (mRNA -> immature -> mature)
DNA state of the next bit
J_rev -> g window -> integrase pulse -> S flip
One reverse event, one gate window, one flip
The flip never precedes the physical trigger
No unassigned events
```

### 动画参数 / Animation settings

- 按拍播放 8 拍 / `Play 8 clock cycles`；
- 底部显示三位读数条带（三级版本）/ `Three-bit readout strip`；
- 顶部同步高亮 $J_{rev}$、门窗口与下一位 $S$ / `Highlight J_rev, gate window and next-bit S in sync`；
- 用于直观展示"一次 $J_{rev}$ 恰好一次进位" / `One reverse event, exactly one carry`。

## 9. Figure 4-7 — 三级失败机制与成熟悬崖 / Level-three failure mechanism and the maturation cliff

### 构图 / Layout

**Panel A — 机制**（四行共享一个 carry 周期的时间轴）：

1. $g_1$，用两种底色区分 **主 carry 窗口**（浅绿）与 **次阈值开口**（浅橙）；
2. 自由 RDF2 与**同一时刻的乘积** $I_2R_2/K_{D,comp}$（两条曲线，双纵轴或归一化）；
   用橙色虚线画出 $=1$ 的 Hill 半点参考线；标出乘积"在主窗口到达前已经越过又回落"；
3. 主 carry 到达时刻的竖线，旁边标注该时刻的 $I_2R_2/K_{D,comp}$ 与 $C_2/K_C$；
4. $S_2$：标出它写到约 0.21 就反弹回中位；用灰色横带标出 $\le0.3$ 的读带边界。

**Panel B — 剂量—响应与悬崖**：散点图，横轴 $\max(I_2R_2)/K_{D,comp}$，纵轴"进入低带的周期数（/12）"；
画出 $=1$ 的参考线；用加粗点标出三个共同成熟对照 60/60（1.56，2）、65/65（0.58，0）、70/70（0.48，0），
并用箭头标出 `Maturation cliff`（悬崖）位置。

底部标注：`Best split-maturation point: 11 crossings vs 12 for the un-split control (14 required)`。

**必须画对的一点**：Panel A 中 RDF2 的下降要标注为"被 $I_2+R_2\to C_2$ 的结合隔离与复合物降解带走"，
**不能**画成"被反向重组消耗"——DNA 反向重组不消耗 RDF2。

Main carry arrival
