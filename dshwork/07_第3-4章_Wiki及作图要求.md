## 1. 网页排版与组件规范

> 本节是**网页组的施工依据**。所有组件名用反引号给出，作为与网页组沟通的固定名词。

### 1.1 页面结构

每章一个独立页面。页面自上而下固定为：

```text
[ 章标题 H1 ]
   ↓
[ 锚点目录 TOC ]            ← 单页内跳转，符合组规；粘性定位
   ↓
[ Hero 区 ]                 ← 一张主视觉 + 一句话结论
   ↓
[ 页面主线 Page Flow ]       ← 竖向流程图（静态图，不做交互）
   ↓
[ 建模完成状态表 ]           ← 状态表，带证据标签配色
   ↓
[ 机制 Mechanism ]           ← 机制图 + 折叠栏放方程
   ↓
[ 判据 Criteria ]            ← 判据定义卡
   ↓
[ 结果 Results ]             ← 主图（可交互）
   ↓
[ 工作窗口 Window ]          ← 热图（可交互）
   ↓
[ 鲁棒性 Robustness ]        ← 矩阵图
   ↓
[ 跨章接口 Interface ]       ← 机制图 + 双向链接
   ↓
[ Engineering ]              ← Design/Build/Test/Learn/Decision 卡片
   ↓
[ Scope & Limitations ]      ← 列表
   ↓
[ 本章结论 ]                 ← 编号列表
   ↓
[ 主图清单 ]                 ← 表格
   ↓
[ 参考文献 ]
```

**TOC 规则**：只列 H2 级别（约 12–14 项）；当前所在节高亮；移动端折叠为一个按钮。

### 1.2 主页面 vs 补充内容 分层规则

**判定规则（三条，逐条判断）**：

1. **放主页面**：该内容回答本章核心问题，且读者不展开就能理解结论；
2. **放折叠栏**：该内容是有结论的细节（方程、完整参数表、方法），读者可能想查但不一定读；
3. **放补充内容**：该内容是穷举性材料（逐点失败清单、完整扫描网格、全部原始轨迹）。

| 内容 | 层级 | 载体 |
|---|---|---|
| 页面主线、核心问题、结论、主图 | 主页面 | 正文 + 图 |
| 机制方程与参数定义 | 折叠栏 | `Mathematical formulation` |
| 判据的完整定义 | 主页面（摘要）+ 折叠栏（全文） | 判据卡 + `Acceptance criteria` |
| 工作窗口热图 | 主页面 | 图 + 交互 |
| 完整参数表（含证据标签） | 折叠栏 | `Full parameter table` |
| 扫描网格逐点结果 | 补充内容 | 表 + 下载链接（站内） |
| 失败点逐点清单 | 补充内容 | `Failure-point list` |
| 复现说明、哈希、运行分级 | 折叠栏 | `Reproducibility` |
| 分子池扰动全矩阵 | 主页面（摘要）+ 补充内容（全表） | 图 + 表 |

**折叠栏命名固定为以下六个，不得自造新名**：

```text
Mathematical formulation
Acceptance criteria
Full parameter table
Failure-point list
Methods
Reproducibility
```

### 1.3 组件库与选型规则

| 组件名 | 用途 | 输入 | 何时选它 |
|---|---|---|---|
| `figure-static` | 静态图 + caption + alt | PNG/SVG | 默认；任何图都能用它 |
| `figure-zoom` | 静态图 + 点击放大 | PNG/SVG 2x | 信息密度高、需要看细节的图（热图、四行同步轨迹） |
| `figure-animated` | 分帧动画播放器 | 帧序列或单图 + 关键帧叠加 | 机制类且**有明确时间顺序**的图 |
| `heatmap-interactive` | 热图 + 悬停读数 | 网格 CSV | 有 2 维参数扫描结果的图 |
| `strip-timeline` | 读数条带 | 逐拍解码结果 | 计数结果图 |
| `threshold-slider` | 拖动参数实时显示通过/失败 | 预计算网格 | 想让读者自己探索窗口的图 |
| `state-card` | 状态卡（输入/判据/结果/边界） | 短文本 | 每个模块的收尾小结 |
| `comparison-toggle` | A/B 切换 | 两组图或两组数据 | 需要对照两种口径时 |

**选型硬规则**：

1. **同一张图不得同时用两种交互组件**；
2. **`figure-animated` 最多每章 1 张**，避免页面过载（第 3 章用 3-2，第 4 章用 4-4）；
3. **`threshold-slider` 只用于工作窗口图**，且必须预先算好网格——不在浏览器里跑模型；
4. 所有交互组件必须有**静态回退**：JS 未加载时显示一张静态 PNG。

### 1.4 交互行为定义（逐项写清，不得只写"可交互"）

每条交互按 **触发 → 变化 → 复位** 三段式描述。

| 图 | 组件 | 触发 | 变化 | 复位 |
|---|---|---|---|---|
| 3-2 | `figure-animated` | 点击播放 / 拖动时间轴 | 四条曲线同步推进；到翻转时刻暂停 1 s，浮现方向判据文字 | 播完停在末帧；再次点击从头播放 |
| 3-4 | `heatmap-interactive` | 悬停网格 | 显示该点参数值、认证结果、最小时间裕量 | 移出即隐藏 |
| 4-4 | `figure-animated` | 点击"逐拍播放" | 顶部高亮 $J_{rev}$ 与 $g$ 窗口；底部条带逐格点亮 | 播完显示完整条带 |
| 4-5 | `threshold-slider` | 拖动浓度标尺滑块 | 实时显示该取值下的认证状态；未认证时整图边框转橙 | 双击滑块复位到认证中心 |
| 4-7 | `comparison-toggle` | 切换 A/B | A 显示机制轨迹，B 显示剂量—响应与悬崖 | 默认 A |
| 3-5 | `comparison-toggle` | 切换"固定相位 / 随机相位" | 矩阵格子重算配色 | 默认"固定相位" |

### 1.5 响应式与移动端降级

| 断点 | 布局 | 降级规则 |
|---|---|---|
| ≥ 1280 px | 正文单栏 1200 px；双联图左右并排 | 全功能 |
| 768–1279 px | 正文单栏 100% 宽 | 双联图保持并排；TOC 折叠为按钮 |
| < 768 px | 单栏 | **双联图改为上下堆叠**；`figure-animated` 改为静态首帧 + 播放按钮；`heatmap-interactive` 隐藏数值格、只保留通过/不通过二值色；`threshold-slider` 改为预设档位按钮 |

**触控**：所有可点元素最小 44 × 44 px；滑块拖柄最小 24 px 直径。

### 1.6 Caption 排版规则

- **位置**：图**下方**，左对齐，与图间距 8 px，与下文间距 16 px；
- **格式**：`**Figure 4-7. Three-bit certification and the paired leak metric.** 说明句…`
  即"粗体编号 + 英文标题 + 句点"后接说明；
- **长度**：标题不超过 12 词；整条 caption **不超过 60 词**，1–3 句；
- **必须包含**（缺一不可）：① 条件（参数/初态/时长）；② 结论（不是"如图所示"）；③ **证据标签**（见 §1.8）；
- **多面板**：用 `(A) … (B) …` 逐面板写，不用分号堆叠；
- caption 与 alt 文本**分开写，不得复用同一串**（见 §1.7）。

### 1.7 图片资产规范

| 图类型 | 格式 | 理由 |
|---|---|---|
| 机制图 / 流程图 / 面板图 | **SVG 优先** + PNG 2x 回退 | 矢量，任意缩放清晰；文字可选中 |
| 数据图（含密集曲线） | **PNG 2x** | SVG 体积过大（数千个数据点） |
| 动画 | PNG 帧序列或 WebP | 逐帧可控 |

- **宽度**：单栏图输出 **1600 px**（对应显示 1200 px）；全宽复合图输出 **2800 px**（对应显示 1400 px）；
- **命名**：`fig<章号><序号>_<slug>.png`，例 `fig04_7_threebit_certification.png`；
- **目录**：`assets/chapter3/`、`assets/chapter4/`（最终路径由网页组确认，本文件不固化）；
- **不得**引用外部图床或外站链接（组规：Wiki 不放外链）。

**Alt 文本规则**：

1. 每张图**必写**，写在组件属性里，不写在正文；
2. 开头**不写** "Image of" / "Figure of"；
3. 必须包含**图的结论**，不只是描述元素；
4. 长度 1–2 句，≤ 200 字符；
5. 数据图必须写出坐标轴含义与关键数值。

> 示例（Figure 4-4）：
> alt = "Two-bit readout over 600 h. Each column is one read window; the decoded
> sequence advances strictly by one modulo 4 with no unlabelled window. Minimum hold
> margin is 2.91 h, which is the binding timing constraint."

### 1.8 无障碍与配色可达性

- **不得只用颜色编码信息**。通过/失败的区分必须同时用**颜色 + 符号**（`✓` / `✗` / `△`）或**填充纹理**；
- **对比度**：正文与图内小字对背景 ≥ 4.5:1。
  - `#33383A` on `#FFFFFF` ≈ 11.6:1 ✅ 正文与坐标文字用它；
  - `#D29144` on `#FFFFFF` ≈ 2.6:1 ❌ **只能用于图形元素、粗体大字（≥ 18 px）与线条**，不得承载小字信息；
  - `#8CA0A5` on `#FFFFFF` ≈ 2.9:1 ❌ 同上，且**不得**用于承载信息的文字；
  - `#304B53` on `#FFFFFF` ≈ 9.0:1 ✅ 可作标题色。
- **色盲**：`#DCEBEC`（浅绿）与 `#F2E2CF`（浅橙）在红绿色盲下接近，**相邻使用时必须配不同图案或直接标注文字**；
- 动画必须提供**暂停**控件，且不自动循环播放超过 3 次。

### 1.9 性能预算

- 单章图片资源总量 ≤ **8 MB**；
- 首屏图片 ≤ 2 张，其余 `loading="lazy"`；
- 动画组件**按需加载**：进入视口才初始化；
- 交互组件的数据（CSV）单独请求，不进首屏包。

### 1.10 网页侧禁止事项

1. **不放任何外站链接**（组规；需要引用文献时用站内参考文献页 + 文末编号）；
2. **不在浏览器端跑模型**（所有交互都是查预计算结果）；
3. **不自动播放声音**；
4. **不把 caption 放进图片里**（caption 必须是可选中的 HTML 文本，便于检索与无障碍）；
5. **不在图内写中文**（英文标签由 §5 / §6 提供，可直接复制）；
6. **不用颜色单独编码通过/失败**（见 §1.8）。

## 2. 作图量化施工规范

> `注意事项.pdf` 只写了"图表 字大线粗、英文"。本节把这句话**量化成可验收的数字**。
> **核心判据不是 pt，而是「最终网页显示尺寸下的像素高度」**——因为图会被缩放。

### 2.1 黄金规则

> **图内任何文字，在最终网页显示尺寸下不得小于 16 px；坐标刻度与辅助文字不小于 14 px；
> 图标题与面板标号不小于 18 px。线条在显示尺寸下不小于 2 px。**

换算公式（美工与建模组都用它核对）：

```text
屏幕像素/每 pt = (dpi / 72) × (网页显示宽度 / 图片输出宽度)
```

### 2.2 字号对照表（三档标准画布）

| 画布 | figsize (in) | 输出 px @ dpi 200 | 网页显示宽 | 缩放 | 屏幕 px/pt | 刻度最小 | 正文标签最小 | 标题/面板标号最小 |
|---|---|---|---|---|---|---|---|---|
| **C1** 单栏数据图 | 8.0 × 5.0 | 1600 × 1000 | 1200 px | 0.75 | 2.08 | 14 px → **7 pt** | 16 px → **8 pt** | 18 px → **9 pt** |
| **C2** 全宽复合图 | 14.0 × 8.0 | 2800 × 1600 | 1400 px | 0.50 | 1.39 | 14 px → **10 pt** | 16 px → **12 pt** | 18 px → **13 pt** |
| **C3** 机制图 | 12.0 × 8.0 | 2400 × 1600 | 1200 px | 0.50 | 1.39 | 14 px → **10 pt** | 16 px → **12 pt** | 18 px → **13 pt** |

**⚠️ 与现有代码的差距（必须修）**：`figures/tempo_style.py` 当前在 C3 画布上使用
`box` 10 pt、`note` 9.5 pt、`hline` 9 pt、`scope` 9 pt、`legend_lines` 9 pt。
按上表，C3 的正文标签最小应为 **12 pt**、辅助文字 **10 pt**。
即**现有机制图文字偏小约 20–30%**，需要统一上调：

| 原语 | 现值 (pt) | 建议值 (pt) |
|---|---|---|
| `box` fontsize | 10 | **12** |
| `note` fontsize | 9.5 | **10.5** |
| `hline` fontsize | 9 | **10** |
| `scope` fontsize | 9 | **10** |
| `legend_lines` fontsize | 9 | **10** |
| `and_node` fontsize | 13 | **13**（已达标） |

### 2.4 画布、边距与导出

| 项 | 规范 |
|---|---|
| dpi | **200**（统一；`tempo_style.save()` 现在写 220，与 `new_canvas()` 的 200 不一致，**统一为 200**） |
| 安全边距 | 四边各留 **≥ 40 px**（@输出尺寸）作为文字安全区；`bbox_inches='tight'` 之后再核对 |
| 出血 | 不需要 |
| 背景 | 机制图纯白 `#FFFFFF`；数据图纯白，**不用透明背景**（透明在深色模式主题下会出问题） |
| 导出 | PNG（`dpi=200`，非隔行）+ 机制图另存 SVG；文件名见 §2.13 |

### 2.5 面板标号与子图

- 面板标号用**大写字母 + 右括号**：`(A)` `(B)` `(C)`；
- 位置：每个面板**左上角外侧**，与面板边缘间距 8 px；
- 字号：**13 pt**（C2/C3 画布），加粗；
