### 2.2 状态编码与位序【共同】

### 2.3 进位事件定义【共同】
Bit *i* 发生 **LR→PB** 时触发进位；PB→LR 不触发。

### 2.4 读出与事件的判定定义【hby 主笔，**新增**】

## 3. 第一部分：进位接口要求

### 3.1 从"持续状态"到"一次有效进位"【共同】
持续的低位 DNA 状态是**信息**；进位是**事件**。整页的共同问题句：
> 低位回零时，如何将持续的 DNA 状态转换成一次有效进位？

### 3.2 有效进位的可量化要求（要求—指标对应表）【hby 主笔】

| 接口要求 | 判定指标 | 扩展模型中的检查方式 |
|---|---|---|
| 每次回零只触发一次写入 | 回零事件 ↔ 进位窗 ↔ 高位翻转 **一一对应** | 14 次进位 / 14 次 bit2 穿越，配对无剩余 |
| 不在错误时刻写入 | 因果顺序；非进位阶段状态变化 | 判据臂 `order` / `alt` |
| 写入足够充分 | 读窗承诺度、距带边距离 | bit2 距带边 **0.2828（低）/ 0.2784（高）** |
| 写完后能保持 | hold 裕量、远驻留期反向通量 | 全局 **setup 4.030 / hold 2.914 h**（受限项 bit1）；bit2 **4.539 / 3.819 h** |
| 能继续接受下一次进位 | 连续正反向交替，而非单次翻转 | 判据臂 `alt`；8 初态 8/8 严格模 8 |

> ⚠️ **措辞纪律**：Hill 的 `K` 是**半饱和参数，不是硬阈值**。现版"峰值必须超过 `K_int`""持续时间必须严格限制在重组时间与复位时间之间"两处都要改。建议表述：
> **进位输入需在合适时段提供足够的写入作用，同时限制写入后的残余作用，使接收位完成一次翻转并稳定保持；其可行范围取决于输入波形与接收位的生化状态。**

> ⚠️ **若尚无真正的幅度 × 宽度输入扫描，就不要给出"已验证的脉冲窗口"。** 这是待建项（L5），不是既有结果。

### 3.3 验收工具【hby 主笔，**新增**】

| 工具 | 产出的量 | 冻结点结果 |
|---|---|---|
| 阈值余量（`check_threshold_margin.py`） | **18 项**操作比 `x/K` 与贴阈值时间 | **仅 1 项被标记**（n=4 时 **16/18**） |
| 配对泄漏（H4） | 配对 R/F 超周期 `L_symmetric` | 5% 切尾 **0.014218**（1% 0.012412 / 10% 0.017646） |
| 严格容差 | 步长与网格敏感性 | 15/15 通过；输出网格 2/2 |

### 3.4 一处诚实的不满足【hby 主笔，**新增**】

被标记的那一项是：

```
term = carry1 H(A1 ; K_A1)
role = "gate arm (must be ~0 between carries)"   ← 该臂自身的定义要求它≈0
ratio_median = 0.9417 ,  frac_time_near_threshold = 0.5275
```

即冻结点上 **A₁/K_A1 中位数 ≈ 0.94**（`K_A[1]=1.2` ⇒ A₁≈1.13，`act(A1;1.2,6) ≈ 0.41`）——**A₁ 臂长期坐在自己的半饱和点附近**。

**正确写法**：非进位期作用确实被压住了，但**不是靠把 A₁ 压到阈值以下**，而是靠 **`R₁`/F1 抑制臂 × Int₀ 时钟 AND** 这一层。这一句同时是 ⑦ 优化一节存在的理由。

## 5. 第三部分：生化实现 —— I1-FFL 如何把状态变化变成脉冲

### 5.1 双分支时序差【zhm 主笔】

### 5.2 方程与符号修正【zhm 主笔，hby 校】

```text
dA₀/dt = α_A·[Bit0_PB] − γ_A·A₀
dR₀/dt = α_R·act(A₀;K₁,n₁) − γ_R·R₀
u_{I1}(t) = α_int·act(A₀;K₂,n₂)·rep(R₀;K₃,n₃)      ← 产生速率（a.u./h），不是浓度
```

* `u_{I1}(t)` 进入各模型整合酶方程的方式见 §6.1 接口协议表。
* 本模型经**稳态匹配**后，源项到 mRNA 源还有一层换算：`transcript_source = u·λ_m·λ_u/(T·k_mat)`；冻结点下 `λ_u = k_mat` ⇒ 系数恰为 **ln2**。

### 5.3 约化模型中的单次进位演示【zhm 主笔】
PB 阶跃触发 → 单次 `Int₁` 脉冲 → 驱动接收位翻转一次。

### 5.4 负自馈与时钟 AND 门的机制【zhm 主笔】
代码对应：`dA₁/dt = α_A[1]·PB₁·rep(A₁;K_auto1,n_auto1) − (γ_A[1]+μ)·A₁`；
`g1 = act(A1;K_A[1],n_A1_gate)·rep(F1;K_F[1],n_F[1])·clock`，`clock = act(Int₀_mature;0.3,2.0)`。

## 6. 第四部分：接口连接验证【hby 主笔，**新增整章**】

### 6.1 接口协议表（连接前必须签字）

| 必须确认 | 本模型实际情况 |
|---|---|
| 输入变量 | 门活性 `g(t)` / 产生速率 / 成熟浓度 —— **三选一** |
| 门输出 | 无量纲 0–1，**两级不同构**：`g0` **无**时钟、`g1` **含**时钟 |
| 源项槽位 | `sources` 是**目标成熟产生速率**，不是浓度 |
| 换算 | 若要接收位成熟 Int 稳态 = L，源项应取 `L·(γ_int[i] + 额外稀释项)`（bit1 的 `γ_int = 1.4`） |
| 单位 | `uM_per_au = 5.75` **未标定**；bit0 路径显式除它 |
| 成熟时间 | 整合酶 20 min；carry 的 A/F **32.5 min**（同一脉冲被两个时间常数滤过） |
| 接收位初态 | 本模型初态**预平衡**（repressor 已预置，避免零点假进位） |
| 验收目标 | 一次翻转 / 连续交替 / 严格计数 —— **三者强度不同** |
| **发送端 / 接收端** | **写明各是哪份模型；本次实验究竟验证什么** |

> `μ` 一律写作"**额外稀释项**"；本冻结点该项为零，而细胞实际生长率（上游 Td = 50 min → 0.8318/h）是另一个量。

### 6.2 波形提取与特征量【hby 主笔】
peak、半高宽、积分剂量、相对回零延迟、脉冲后尾部、进位间残余输入。

**纪律**：
* 浓度波形的积分单位是"浓度×时间"、产生速率的是"浓度"，**不能都叫 dose**；
* **正向写入与反向写入两类进位必须分开统计**——单窗口径的离散度是 **2.87×10⁶ 倍**，配对超周期口径是 **0.08%**（H4 的由来）。

### 6.3 真实波形 vs 理想脉冲【共同】
匹配峰值 / 匹配半高宽 / 匹配剂量是**三种不同对照**，分别说明。

### 6.4 证据边界【hby 主笔，**必写**】
* 发送端、接收端、方程同出一套模型时，回放成功**主要证明接口拆分与实现一致**，不是独立生物学验证；
* 本模型内 `sources = (None, α_Int[0]·g0, α_Int[1]·g1)` —— **bit1 的整合酶本来就由 bit0 的门输出驱动**，全链已联合积分。同模型回放应定位为**接口审计**；
* 跨模型成功也只支持"**指定接口与条件下的兼容性**"，不等于普遍可迁移性。

## 8. 失效诊断【本章扩为三类】

### 8.1 提前进位【zhm 主笔】
不该翻转时发生翻转 → 约束非进位期作用与输入时机。

### 8.2 写入不充分【hby 主笔，**新增**】
该翻转时没有完成状态切换。n=4 匹配运行：**14 次进位只有 5 次翻转 bit2**、**17 个读窗位标签从未确定**，bit2 自 t ≈ 38 h 翻上去后不再回低态。

### 8.3 过度穿越与相位偏移【hby 主笔，**新增**】
进位次数超过应有值：`conc_scale|f=1.2` → 26 次穿越 / 13 次门；`|f=1.1` → 正确但带相位偏移。

### 8.4 三类失败对设计的启示【共同】
分别对应：输入时机、有效输入与接收位准备状态、尾部与双向反应。

## 9. 优化：表达时序与门响应

### 9.1 方案 A：A₁ 负自馈【zhm 主笔】

### 9.2 方案 B：Int₀ 与进位信号的**杂合启动子 AND 门**【zhm 主笔，hby 正名】

> **不叫 Split System。** 其候选实体实现可以是杂合启动子，也可以是拆分整合酶；但本模型只实现了前者。

### 9.3 门响应优化：`n_A1_gate`【hby 主笔，**新增**】

这是让三位成立、而现版完全未提的**第三个设计要素**：

* 门臂指数独立为 **6**，而 F1 产生指数仍为 **4**（`ZENG["n_A"][1]` 未被改动）；
* 级间不对称：`g0` **无**时钟，而 **34 状态二位模型在无时钟的 `g0` 下就已认证**；三位才需要 `g1` 的时钟 AND 门 ⇒ **进位整形的要求随级联深度上升**；
* 量化支撑：阈值余量在 n=4 时 **16/18** 被标记、n=6 时仅 **1/18**。

### 9.4 修正版 n=4 / n=6 对照【hby 主笔】
**它证明的是"接口质量需要优化"，不是"有脉冲一定优于持续输入"。** n=4 配置**已含 I1-FFL 与时钟门**，只是 A1 臂指数不同——所以它不是"持续输入"的对照。

### 10.3 确定性 vs 概率：证据边界【hby 主笔，**必写**】
有限确定性仿真中的**事件计数不等于真实单细胞概率**。`<1%` 只能是**未来设计目标**。
项目自身的预审判决原文：**"A stochastic study is REQUIRED before any counting claim."**

### 10.4 敏感性：已做与计划【hby 主笔，重做】
* **已做**：局部可辨识性（秩 **9**、条件数 **212.49** 理论 / **462.53** 实验；1–2% 步长收敛 0.012，**5% 步长不收敛 0.171，不得作为局部估计引用**）；三个旋钮的对称认证宽度：`conc_scale` **0.00**、`K_A1` **0.05**、`clock_K` **0.20**（且为**已测网格点集合，不是连续可靠范围**）。
* **计划**：Sobol / 全局方差分解 —— 全树零命中，**必须标为计划**。

### 10.5 正交性与实体实现边界【共同，hby 主笔边界段】
* **本模型假设各位完全正交、无跨位项** ⇒ 它对标的正是"三个理想正交模块"；
* ΦC31 / Bxb1 / TP901-1（+ BM3R1 / PhlF / PsaR）只能写作**候选实体实现**；
* 所引 Weinberg 2017（*Nat Biotechnol* 35:453-462）是**哺乳动物细胞**的大规模电路工作，**不能替代**在目标宿主中对这三套"整合酶—阻遏蛋白—RDF"组合的验证。

### 10.6 架构选择建议【共同，降级】
只给"**已测配置内的边界**"：在 `n_A1_gate=6`、`clock 0.3/2.0`、`uM_per_au=5.75` 下，进位频次与稳定性成立。
**不推荐**"优先拆分整合酶"——模型无拆分动力学、无公平对照，且实际杠杆是**门臂指数**。
