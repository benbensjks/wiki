# Scaling from One Bit to Multi-bit Counting — 架构大纲

**本页回答的问题**
> 当低位发生正确的回零时，如何只向高位传递一次有效的进位信息。

**覆盖范围**：进位接口要求 → 候选架构分层比较 → I1-FFL 生化实现 → 接口连接验证 → 扩展模型的二位与三位连续计数 → 失效诊断 → 优化 → 鲁棒性与实现边界。

**页面定位**：本页建立在单 Bit 拓扑动力学之上，把"信号要求"与"生化实现"组织成一条承接链，并在含真实上游、表达动力学与显式复合物的扩展模型中检验多位计数。

## 2. 系统规范与共同前提

### 2.1 单 Bit 基础
重组速率方程、构象修饰、`BM3R1` 延迟网络。共同正文只讲一次；两套数学表达放补充材料。

### 2.2 状态编码与位序
Bit0 = 最低有效位，Bit1 = 中间位，Bit2 = 最高有效位；状态向量记作 `(Bit2, Bit1, Bit0)`。

### 2.3 进位事件定义
Bit *i* 发生 **LR→PB**（复位归零）时触发进位；发生 PB→LR 时不触发。

### 2.4 读出与事件的判定定义

| 判定项 | 定义 | 冻结值 |
|---|---|---|
| 读窗 | 通量谷值 **±10%**（占周期 20%） | 时钟周期 10.60 h；进位周期 42.4 h（= 4 拍）；读窗中位 **2.1333 h = 20.13%** |
| 读带 | 低带 ≤ 0.30，高带 ≥ 0.70 | 高带占比 ≥ 0.80 记 1；低带占比 ≥ 0.80 记 0 |
| 承诺度 | 读窗内落在带内的比例 | 冻结点 `commitment_min_all_bits = 1.0` |
| 稳态读数 | **丢弃一个完整计数周期**后的窗口 | 600 h → 56 读窗；drop 8 → **48** 稳态读 |
| 未标注窗 | 两带占比均不足 | 冻结点 **0**（168/168 位标签全部提交） |

### 2.5 跨模型一致性检查

约化模型的 P1–P8 映射与扩展模型的冻结读出序列逐位一致：

P1(0,0,1)=1 → P2(0,1,0)=2 → … → P7(1,1,1)=7 → P8(0,0,0)=0
扩展模型冻结读出：12345670 12345670 …（600 h，序列精确，0 未标注）

## 3. 进位接口要求

### 3.1 从持续状态到一次有效进位
低位的 DNA 状态是**持续存在的信息**；进位是**只发生一次的事件**。用一个随低位状态持续表达的信号驱动高位，高位可能在整段驻留期持续受激，即使出现过一次正确翻转也未必停在正确状态。

### 3.2 有效进位的可量化要求

| 接口要求 | 判定指标 | 扩展模型中的检查方式 |
|---|---|---|
| 每次回零只触发一次写入 | 回零事件 ↔ 进位窗 ↔ 高位翻转 **一一对应** | 14 次进位 / 14 次位 2 穿越，配对无剩余 |
| 不在错误时刻写入 | 因果顺序；非进位阶段状态变化 | 判据臂 `order` / `alt` |
| 写入足够充分 | 读窗承诺度、距带边距离 | 位 2 距带边 **0.2828（低）/ 0.2784（高）** |
| 写完后能保持 | hold 裕量、远驻留期反向通量 | 全局 **setup 4.030 / hold 2.914 h**（受限项为位 1）；位 2 为 **4.539 / 3.819 h** |
| 能继续接受下一次进位 | 连续正反向交替，而非单次翻转 | 判据臂 `alt`；八初态 **8/8** 严格模 8 |

**两条措辞纪律**

1. Hill 关系中的 `K` 是**半饱和参数，不是硬阈值**：峰值超过它不保证完成写入，持续的次阈值作用也可能累积。建议表述为：
   > 进位输入需在合适时段提供足够的写入作用，同时限制写入后的残余作用，使接收位完成一次翻转并稳定保持；其可行范围取决于输入波形与接收位的生化状态。
2. **在完成真正的幅度 × 宽度输入扫描之前，不给出"已验证的脉冲窗口"**；该扫描列为 L5。

### 3.3 验收工具

| 工具 | 产出的量 | 冻结点结果 |
|---|---|---|
| 阈值余量扫描 | **18 项**操作比 `x/K` 与贴阈值时间占比 | **仅 1 项被标记** |
| 配对泄漏（H4） | 配对 R/F 超周期 `L_symmetric` | 5% 切尾 **0.014218**（1% 0.012412 / 10% 0.017646） |
| 严格容差 | 差分步长与输出网格敏感性 | 15/15 通过；输出网格 2/2 |

### 3.4 阈值余量的实测结论

18 项中唯一被标记的一项是进位门的 `A₁` 臂：

```
carry1 H(A1 ; K_A1)
该臂自身的定义要求：非进位期应 ≈ 0
ratio_median = 0.9417      贴阈值时间占比 = 0.5275
```

即冻结点上 **`A₁/K_A1` 中位数 ≈ 0.94**（`K_A[1] = 1.2`，故 `A₁ ≈ 1.13`，`act(A₁;1.2,6) ≈ 0.41`）：**`A₁` 臂长期位于自己的半饱和点附近**。因此非进位期的低作用并非由"`A₁` 被压到阈值以下"实现，而是由 **`R₁`/F1 抑制臂 × Int₀ 时钟 AND** 这一层承担。这是 §9 优化一节存在的直接理由。

## 5. 生化实现：I1-FFL 如何把状态变化变成脉冲

### 5.1 双分支时序差
低位回零后，激活臂增强、抑制臂随后积累，两者之间形成一个窗口：**激活已足够而抑制尚未建立**，下级整合酶在此期间被产生，随后输出关闭。

### 5.2 方程

```text
dA₀/dt    = α_A · [Bit0_PB] − γ_A · A₀
dR₀/dt    = α_R · act(A₀; K₁, n₁) − γ_R · R₀
u_{I1}(t) = α_int · act(A₀; K₂, n₂) · rep(R₀; K₃, n₃)
```

`u_{I1}(t)` 是**产生速率（a.u./h）**，进入整合酶方程的方式见 §6.1。本模型经**稳态匹配**后，源项到 mRNA 源还有一层换算：`transcript_source = u · λ_m · λ_u / (T · k_mat)`；冻结点下 `λ_u = k_mat`，故系数恰为 **ln2**。

### 5.3 约化模型中的单次进位演示
PB 阶跃触发 → 单次 `Int₁` 脉冲 → 驱动接收位翻转一次。

### 5.4 负自馈与时钟 AND 门

```text
dA₁/dt  = α_A[1] · PB₁ · rep(A₁; K_auto1, n_auto1) − (γ_A[1] + 额外稀释项) · A₁
g1      = act(A1; K_A[1], n_A1_gate) · rep(F1; K_F[1], n_F[1]) · clock
clock   = act(Int₀_mature; 0.3, 2.0)
```

### 6.2 波形提取与特征量
提取：峰值、半高宽、积分剂量、相对回零事件的延迟、脉冲后尾部、两次进位之间的残余输入。

* 浓度波形的积分单位是"浓度×时间"，产生速率的是"浓度"，两者不可同列。
* 两类进位分开统计（见 §0.3）。

### 6.3 真实波形与理想脉冲的对照
同时做两种输入：生化网络提取的**真实波形**，与按预先说明方式构造的**理想脉冲**（如等剂量方波）。匹配峰值、匹配半高宽、匹配剂量是三种不同对照，分别说明。

### 6.4 证据边界

* 当发送端、接收端与方程同出一套模型时，回放成功主要证明**接口拆分与实现一致**，属接口审计，不作为独立生物学验证。
* 本模型中 `sources = (None, α_Int[0]·g0, α_Int[1]·g1)`：位 1 的整合酶本来就由位 0 的门输出驱动，全链已联合积分。
* 跨模型连接成功支持"**指定接口与条件下的兼容性**"，不等于普遍可迁移性。

## 8. 失效诊断

### 8.1 提前进位
不该翻转时发生翻转 → 约束非进位期作用与输入时机。

### 8.2 写入不充分
该翻转时未完成状态切换。`n_A1_gate = 4` 的匹配运行：**14 次进位中仅 5 次翻转位 2**、**17 个读窗位标签从未确定**，位 2 在 t ≈ 38 h 翻上去后不再回到低态。

### 8.3 过度穿越与相位偏移
进位次数超过应有值：浓度因子 1.2 → **26 次穿越 / 13 次门**；因子 1.1 → 读数正确但带**相位偏移**。

### 8.4 三类失败对设计的启示

| 失败类型 | 现象 | 对设计的启示 |
|---|---|---|
| 提前进位 | 不该翻转时发生翻转 | 约束非进位期作用与输入时机 |
| 写入不充分 | 该翻转时未完成切换 | 检查有效输入与接收位准备状态 |
| 过度穿越 / 回退 | 写入后又发生额外变化 | 检查尾部作用与双向反应 |

## 9. 优化：表达时序与门响应

### 9.1 方案 A：`A₁` 负自馈调控
`A₁` 启动子改为负反馈关断，压缩静态期的驱动水平。

### 9.2 方案 B：`Int₀` 与进位信号的杂合启动子 AND 门
`Int₂` 的表达强制依赖外源时钟脉冲 `Int₀` 与上位进位信号；实体实现可为杂合启动子或拆分整合酶，本模型实现的是**杂合启动子门控**。

### 9.3 门响应优化
让三位成立的关键设计要素之一：**门臂指数独立取 6**，而 F1 产生臂指数仍为 **4**（表值未被改动）。

级间结构不对称：`g0` **无**时钟，而 **34 状态二位模型在无时钟的 `g0` 下即已认证**；三位才需要 `g1` 的时钟 AND 门。即**进位整形的要求随级联深度上升**。

量化支撑：阈值余量在 `n = 4` 时 **16/18** 被标记，`n = 6` 时仅 **1/18**。

### 9.4 `n = 4` / `n = 6` 门指数对照
`n = 4` 配置**已含 I1-FFL 与时钟门**，仅 `A₁` 臂指数不同。该对照说明的是**接口质量需要优化**，不作为"脉冲输入优于持续输入"的证据。

### 10.3 确定性验证与概率指标的证据边界
有限确定性仿真中的**事件计数不等于真实单细胞概率**。`< 1%` 只能作为**未来设计目标**。以本页判据为前提的随机性研究尚未开展。

### 10.4 敏感性：已完成与计划

* **已完成**
  * 局部可辨识性：有效秩 **9**，条件数 **212.49**（理论）/ **462.53**（实验观测）；1–2% 差分步长收敛（矩阵变化 0.012），**5% 步长不收敛（0.171），不得作为局部估计引用**。
  * 三个旋钮的对称认证宽度：浓度因子 **0.00**、`K_A1` **0.05**、`clock_K` **0.20**；三者均为**已测网格点集合，不是连续可靠范围**。
  * 单参数鲁棒性扫描（21 点）与池/峰值扰动。
* **计划**：Sobol 全局方差分解及参数敏感性排行。

### 10.5 正交性与实体实现边界
* 本模型**假设各位完全正交、不含跨位作用项**，因此它对标的是三个**理想正交模块**。
* 具体酶与阻遏蛋白组合（如 ΦC31 / Bxb1 / TP901-1 与 BM3R1 / PhlF / PsaR）作为**候选实体实现**列出，不作为已验证结论。
* 所引 Weinberg 等（2017，*Nat Biotechnol* 35:453-462）为**哺乳动物细胞**中的大规模遗传电路工作，不能替代在目标宿主中对上述组合的验证。
* 高浓度 RDF 的细胞毒性、多级级联的代谢负载均属待评估项。

### 10.6 架构选择建议
只给出**已测配置内的边界**：在 `n_A1_gate = 6`、`clock 0.3 / 2.0`、`uM_per_au = 5.75` 下，进位频次、保持能力与连续计数成立。未测配置与更深的级联不在本页结论范围内。
