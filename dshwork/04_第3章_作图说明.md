## 3. Figure 3-1 — 单比特开关机制 / Single-bit switch mechanism

### 构图 / Layout

中央是 DNA 双状态，四周是三个分子与复合物，四条通量箭头连回 DNA：

```text
                 BM3R1 (T)
                     │ repression
                     ▼
   Int (I) ──binding──▶ Int–RDF complex (C) ──▶ Reverse recombination ──┐
      │                                                                  ▼
      └──────── Forward recombination ────────────────▶  DNA state (PB ⇄ LR)
                                                                         │
                                          S decides production split ────┤
                                                                         ▼
                                                                   RDF pool (R)
```

左侧画一个「记忆」小框：RDF pool 在 LR 驻留期累积、在 PB 期被清空。

**必须画对的三点**（在图上用小字标注）：

1. `Memory is stored in the RDF pool, not in Int`；
2. `Reverse recombination is driven by the complex`；
3. `S high → BM3R1 low → RDF high`（连线方向不能反）。

### 可直接粘贴的英文

```text
Single-bit switch
DNA state (PB / LR)
PB fraction = 1 - S
LR fraction = S
Integrase (Int)
RDF
BM3R1
Int-RDF complex
Forward recombination (PB->LR)
Reverse recombination (LR->PB)
RDF pool (memory)
Memory is stored in the RDF pool, not in Int
Reverse recombination is driven by the complex
S high -> BM3R1 low -> RDF high
Free Int drives the forward reaction
The complex drives the reverse reaction
BM3R1 represses RDF production
```

## 4. Figure 3-2 — 单周期翻转分解 / One-cycle flip decomposition

### 构图 / Layout

上下四行共享同一条时间轴（一个时钟周期，约 10.6 h）：

1. **第一行**：$S$（DNA 状态），背景画读带 0 / 1 与灰区；
2. **第二行**：$R$（RDF 池）与 $C$（复合物），两条曲线量纲不同，建议用双纵轴或归一化；
3. **第三行**：正向与反向重组通量，同轴对比；
4. **第四行**：时钟输入通量（真实 C31），标出脉冲位置。

在翻转时刻画一条竖直虚线，并在旁边标注：

- `Direction is set by the RDF pool at the pulse`；
- `Forward and reverse are separated in time`。

### 可直接粘贴的英文

```text
One clock cycle
DNA state S
Read band 0 / 1
Ambiguous band
RDF pool
Int-RDF complex
Forward flux
Reverse flux
Clock input (C31 translation flux)
Direction is set by the RDF pool at the pulse
Forward and reverse are separated in time
RDF accumulates during the LR dwell
RDF is emptied during the PB dwell
```

### 动画参数 / Animation settings

- 循环时长 / `Loop duration: 8-12 s`；平滑相位切换 / `Smooth phase transitions`；
- 建议在翻转时刻暂停 1 s 并浮现方向判据文字。

## 7. Figure 3-5 — 扰动与容差 / Perturbation and tolerance

### 构图 / Layout

- 浅绿 `Recovered original phase`；
