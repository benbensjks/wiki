## 1. 模型需求(来自 Week4_RDF_REV 双初态扫描)
- RBS0.45 工作点:确定性窗口 **k = 3–24 h⁻¹**(双初态通过临界 2.8;25 起碎裂退化带,27 起稳定失效)
- 随机异质性下**全稳平台 k = 6–18 h⁻¹**(30/30 实例),边缘档 5 与 22;中心建议 8–16
- 机制:下界=脉冲间隙游离 Int 累积(防多翻);上界=LR→PB 回翻失败/周期卡滞(非单调)

## 2. 体系机制(一手)
- ssrA 11-aa = AANDENY(SspB 适配器位点)+ ALAA(ClpX 孔位点);**两段齐全才高效**:有 SspB 时 WT ssrA KM≈0.47 µM vs 无 SspB 3.38 µM(7×)(Molecules 2021 体外;SENY 连接体不改变 KM 但使体外达稳态 ~15 min vs ~60 min,即递送更快)
- 体内 ≥90% 走 ClpXP(Lies 2008 摘要:WT k≥1.4 min⁻¹、SspB⁻ 降 3×、clpX⁻ 0.10 min⁻¹、lon 0.05 min⁻¹);**限速=去折叠排队,瓶颈=ClpX**(Jadhav 2025:仅 ClpX 过表达显著解除排队;ClpP 过表达中等加速、机制归结为“提高 X/P 相遇概率”;SspB 无效)
- C 端三残基决定强度:LAA≥LVA > AAV > ASV > DAS(Molecules/Andersen/Jadhav 一致)

**裁决**:Andersen 40 min 是荧光口径的系统性高估(慢偏);以 Szydlo 的直接测量为准,**E. coli 原生 ssrA 表观 t½≈6–14 min(k≈3–8 h⁻¹,菌株依赖)**。
**含义**:原生 ssrA 已覆盖模型窗口低缘(RBS0.45,tag 3–8 得分 0.98–1.00)——不是“肯定不够”;**LAA-LAA/ClpX 共表达有望推向 6–18 全稳带**。

## 4. 候选排序(工程可实现性)

| 优先级 | 候选 | 依据 | 预期 k_tag |
|---|---|---|---|
| **A1** | 原生 ssrA `AANDENYALAA` | Szydlo 6–14 min;Molecules 最快档;BBa_M0050 | **3–8 h⁻¹(窗口低缘)** |
| **A2** | LAA-LAA(6-aa,仅 ClpX 位点) | Jadhav:唯一比原生快的短标签(残留 13.7% vs 37.2%,速率比 3.7×;低诱导 4.0% vs 16.7%,比 4.8×) | 换算 **14–38**(锚定原生 3–8),随诱导饱和 |
| A3 | 原生/LAA-LAA + **ClpX 共表达** | Jadhav:解除排队的首要杠杆 | 更高,代价=负载 |
| B | SsrA2X(双位点) | Jadhav 次快;但速率随诱导交叉(Ara 0.1% 时≈LAA-LAA,≥0.2% 时反超 30–40%) | 低诱导 ≈20–24;**强饱和,不可定带** |
| B′ | LAA+4 | S2 残留 37.4%≈原生 | ≈原生档 |
| C | AANDENYSENYALAA | Molecules:体外递送最快(~15 min 达稳态);体内并列第一档 | ≈A1(体外优势体内无差异) |
| 淘汰 | AAV/ASV/LVA/DAS(经典“慢变体”) | 全部慢于原生 60–110 min 档 | —(除非要慢速档) |

**宿主与底物双重不可外推**:BL21 vs MV1190 差 ~5×(6 vs 40 min,混菌株+口径);GFP(27kDa)vs φC31 Int(~55kDa,含 DNA 结合域)去折叠更慢 → **MC4100 + Int 融合实测是唯一裁判**。

## 5. 实测方案(给实验组,报告期内)
1. 同启动子/RBS:sfGFP–{A1, A2, A3(±ClpX), B, B′, C} 六档;去诱导剂+翻译抑制双法测 t½(单法不可靠,见 §3)
2. Int–标签融合活性对照(attP×attB 翻转效率),确认 C 端融合不破坏 φC31 活性
3. ClpX 共表达的负载代价(生长曲线/对振荡器周期影响)
4. 达标判据:门槛 k_tag≥3 h⁻¹(t½≤14 min);目标 6–18(全稳);k∈[3,5) 裕度小需评估
5. 若 MC4100 实测 A1 也 <3 h⁻¹:回建模降 RBS/改接口/先上 ClpX(矩阵有全部 tag<4 数据)

## 6. 与模型窗口的对账(数值核验)
- 下界:k=3 → 0.98;k=2.8 → 双初态 0.975/0.976;k=2.5 → 0(PB 初态)/0.92(LR);k=2.4–2.7 初态依赖的易碎带
- 上界:RBS0.45,tag 24 → 0.997;25/27 → 0.24;26 → 0.99 但含中间态样本(M 判据 0.4–0.8);28+ 回翻失败/卡滞(0–0.49)
- MC(30 实例/档,P 判据):3→0.81±0.36(失败 7/30);5→0.97(1/30);6–18→≥0.99(0/30);22→0.91(5/30);25→0.74(12/30);26→0.60(19/30)
- 判据口径:P=banded toggle score(主),M=二值化匹配率(辅);同一档两个口径的差异见上(26 档 P 0.99 / M 0.4–0.8)
