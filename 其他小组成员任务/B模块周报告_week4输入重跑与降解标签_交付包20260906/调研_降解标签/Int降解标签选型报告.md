## 0. 执行摘要（一页结论）

1. **模型硬需求**：Int 标签速率 $k_{tag,int}$ 的确定性窗口为 **3–24 h⁻¹**（RBS0.45，双初态 100 h 审计；双初态同时通过的临界 2.8，2.4–2.7 为初态依赖的易碎带；25 起碎裂、27 起稳定失效）；中心设计区 8–16（全稳平台 6–18）。
2. **选型结论（按优先级）**：
   - **A1：原生 ssrA 标签 `AANDENYALAA`（C 端）**——E. coli 内 GFP 融合实测表观 t½≈6–14 min（k≈3–8 h⁻¹，Szydlo 2022 直测），恰好覆盖门槛区（RBS0.45 下 k=3 得分 0.98）；最低风险、序列/parts 现成。
   - **A2：LAA-LAA 六肽标签**（Jadhav 2025，仅 ClpX 位点，体内快于原生 ssrA）——目标推入 6–18 全稳平台；换算 k≈14–38（随诱导饱和），精确序列为推断值 `LAALAA`（实验前置必办）。
   - **A3：A1/A2 + ClpX 共表达**——Jadhav 证明 ClpX 是降解排队瓶颈、过表达主要提速项（ClpP 中等、SspB 无效）；风险：蛋白酶负载。
3. **数值门槛与判据**：实测 k≥3 h⁻¹ = 可工作（t½≤14 min）；k∈6–18 = 全稳；若实测 <3 → 优先 ClpX 共表达（增强因子 ≈6/k₀），再考虑后备方案。
4. **首要实验问题（一次实验同时回答）**：(a) Int 融合后实际速率比 GFP 慢多少（55 vs 27 kDa，去折叠是风险点）？(b) C 端融合是否破坏整合酶活性？
5. **已淘汰**：经典“慢档”变体 AAV/ASV/LVA/DAS（模型验证 0.4–0.6 失败）；Andersen 1998 “40 min” 为荧光口径高估，不作否决依据。

## 1. 模型窗口（双初态 100 h 审计；判据见 Week4_RDF_REV 报告 §2）

- 工作点：RBS0.45 / krep15 / krdf200 / K18.6 nM / n3.4
- **失效临界（RBS0.45）**：k=2.4–2.7 → 初态依赖（0–0.95 漂摆）；k=2.8 → 双初态均 0.975；k=3 → 0.981；k=4–24 → 0.99–1.00
- **上缘**：24 → 0.997；25/27 → 0.24；26 → 0.99（但含中间态样本，M 判据 0.4–0.8）；28+ → 回翻失败/卡滞（0–0.49）
- **联合工作区**：全稳平台 tag 6–18 × RBS 0.30–0.60；低速档 k≤4 需 RBS≤0.45–0.55；高速档 19–28 需 RBS≥0.35–0.55（按档位递增）
- 机制：下界=脉冲间隙游离 Int 累积（防多翻）；上界=LR→PB 回翻失败、周期卡滞（非单调）

## 3. 系统级风险

- A 模块阻遏物/C31 均无标签、仅稀释（week4 质粒定稿 & 染色体版一致）→ 无 A+B 双标签竞争 ClpXP
- B 内 Int 脉冲峰时刻 ClpXP 瞬时饱和（自队列）与 30% 负载压力 → 最终构型功能复测覆盖（Jadhav S3 饱和数据为同类证据）
- Int 55 kDa > GFP 27 kDa → 悲观 3× 已建模（失败），必须以实测为准
- E. coli 内 integrase–ssrA 直接先例未检索到（2026-09-06）→ Int 活性自测为前置条件

## 4. 实验方案（梯度标尺法）

同启动子/RBS 的 sfGFP–{无标签, 原生 ssrA, LAA+4, SsrA2X, LAA-LAA} 五档 + Int–原生 ssrA/未融合对照 + ClpX 共表达备用株；去诱导剂+翻译抑制双法交叉；低诱导测量（S3 显示 0.2% Ara 即近饱和拐点）；宿主 MC4100、37°C。

**决策**：实测 k∈6–18 → 直接采用；k∈[3,5) → 可用但裕度小（3 档约 77% 稳）；k<3 → 上移一档 + ClpX 共表达；k>24 → 下移一档或按联合工作区上调 RBS（需复核稳健性）。
