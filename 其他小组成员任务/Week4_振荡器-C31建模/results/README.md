# Frozen result summaries

The CSV files in this directory are copied from the completed, report-generating runs. They are retained as evidence for the report and are not overwritten by new runs.

| File | Content |
|---|---|
| `deterministic_ODE_summary.csv` | reduced/full ODE comparison and QSS validation |
| `engineering_sensitivity_summary.csv` | one-at-a-time engineering scan |
| `translation_burden_summary.csv` | flux-driven resource-load boundary |
| `AB_robustness_summary.csv` | long deterministic A/B design robustness |
| `stochastic_condition_summary.csv` | stochastic condition-level period summary |
| `stochastic_period_ratio_bootstrap.csv` | sponge/no-sponge period ratios and confidence intervals |
