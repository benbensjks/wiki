# 第3章 Coupling the Clock to a Single-bit Counter
## 把时钟脉冲转换成一位记忆

### 3.1 Why a bit? — 为什么需要一个比特

振荡器告诉细胞“又经过了一个周期”，计数器则记录“已经经过了多少个周期”。我们将韩亚轩的repressilator–ϕC31模型接入重组开关，直接使用其C31翻译通量，而不是人为规定DNA按时翻转。

单比特的目标是：每次有效时钟输入后，DNA读出在0和1之间交替，并在两次输入之间保持可读状态。

### 3.2 How one bit works — 同一个输入为何能使DNA来回翻转

🟨 **Figure 3-1 — Single-bit memory / 单比特记忆机制**

DNA有两种构型：PB记作0，LR记作1。Int推动正向重组；RDF与Int形成的复合物支持反向重组。BM3R1（模型中的T）控制RDF何时积累。

| 当前构型 | 分子池的状态 | 下一次Int脉冲的主要作用 |
|---|---|---|
| PB／0 | PB驱动BM3R1，抑制RDF产生 | RDF较低，PB→LR |
| LR／1 | BM3R1逐渐清除，RDF开始积累 | Int与RDF形成复合物，LR→PB |

因此，同样的时钟输入可以得到相反方向的写入：**DNA构型和相关分子池共同保存历史，RDF存量参与选择下一次重组方向。**

模型把每一位展开为11个连续状态，包括Int、BM3R1、RDF的转录与成熟过程、显式Int–RDF复合物，以及DNA构型比例。完整ODE放在Methods，不在主页面逐项展开。

### 3.3 When is a bit readable? — 连续轨迹怎样读成0和1

📈 **Figure 3-2 — Switching and read windows / 翻转与读窗**

设S为DNA处于LR构型的比例，PB比例为1−S。每个时钟周期在通量谷附近设置一个读窗，总宽为周期的20%。窗口内至少80%的采样满足S≤0.3时记0，满足S≥0.7时记1，否则记为未定义。

这让读出同时要求“电平够高／够低”和“保持足够久”。代表轨迹显示，正反重组随分子池状态交替占优，S在有效读窗中稳定进入对应带；完整生化初态的续跑与S扰动实验进一步支持状态记忆。

早期单点、0.2/0.8阈值曾漏判部分交替轨迹，因此我们公开读窗与阈值。它们是本项目的工程验收规则，不是通用实验标准。旧800点扫描和逐跃迁表放入补充材料，避免打断页面主线。

**本章结论：真实时钟输入可以驱动一个可读的单比特；接下来要解决的是如何把它的归零转换成下一位的进位。**

# 第4章 Scaling from One Bit to Multi-bit Counting
## 用进位把一位扩展成三位

### 4.1 From reset to carry — 怎样让下一位只翻转一次

🟨 **Figure 4-1 — Carry architecture / 两级进位机制**

如果直接用上一位的长时间状态平台驱动下一位，下一位可能提前翻转或持续受到输入。我们采用非相干前馈环（I1-FFL）：A激活下一位整合酶表达，同时驱动抑制因子F；F的后续积累压低表达，使输出形成有限脉冲。

```text
上一位PB比例 → A → 下一位整合酶表达
                └→ F ─┤ 下一位整合酶表达
```

两级进位有所不同：

- **bit0→bit1：** A0/F0调控Int1。
- **bit1→bit2：** A1/F1调控Int2，同时保留A1负自馈和Int0时钟AND门。

A和F均经过mRNA→未成熟蛋白→成熟蛋白链；进位进入下一位已有的整合酶表达链。F是进位阻遏因子，不能与重组方向性因子RDF混为一谈。

每次进位不仅检查码串，还核对：前一位反向重组、门窗口和后一位翻转在时序上匹配，不能出现多余事件。这里是连续动力学产生的行为，分析器不参与控制翻转。

### 4.2 First validate two bits — 先让两位稳定计数

📈 **Figure 4-2A — Two-bit counting / 两比特结果**

将两个11状态比特与完整A0/F0表达链接入上游后，得到34状态模型。代表工作点在300 h内给出28个有效读窗，重复输出：

```text
01 → 10 → 11 → 00
 1 →  2 →  3 →  0
```

75点联合参数扫描中，53点满足既定的读出与事件验收。选定点为浓度换算5.75、carry mRNA半衰期2 min、A0/F0成熟半衰期32.5 min；四种轨道自洽初态均能继续计数。扫描结果说明存在已测试的可行邻域，不代表实验成功率或整个连续参数空间都可行。

### 4.3 Why the third bit needed a sharper gate — 第三位需要怎样的门

📈 **Figure 4-3 — Gate redesign / 从失败到可用的第三级**

加入bit2后，仅延长A1/F1表达时间未能得到稳定模8计数。分析发现，门开关时序、次阈值输入与RDF／复合物存量相互影响：有主脉冲并不代表下一位能完成正确写入。

我们随后把A1对Int2门的Hill指数独立出来，只提高该门的陡度，保持F1产生指数为4。这样可以比较门形状本身的作用，而不同时改变抑制臂的产生方式。

| 独立门指数 | 已测试的4组表达参数组合 |
|---|---|
| n=4 | 0/4通过 |
| n=5、6、7、8 | 各4/4通过 |

为比较残余错误重组，我们把一个正向carry与一个反向carry组成完整超周期，分别统计门开、尾巴和远驻留期的通量。按同一口径，n=6的对称泄漏指标较n=5明显降低，而继续提高到7–8的收益趋小。因此选择 **n_A1_gate=6**。

这是新增的模型设计参数，尚不对应已经实现的生物元件。结果支持“该范围内独立加陡有效”，不证明精确分界一定在n=5，也不意味着延长表达时间在所有配置下都无效。

### 4.4 Three bits, eight states — 三级计数结果

📈 **Figure 4-2B — Three-bit counting / 三比特结果**

最终模型共有51状态：6个上游状态、3个11状态比特，以及两套完整A/F表达链。前34状态保留为两比特模型的精确前缀；在当前单向耦合假设下，新增bit2不反馈改变前级。

600 h代表运行产生56个有效读窗，严格按模8递增：

```text
001 → 010 → 011 → 100 → 101 → 110 → 111 → 000
  1 →   2 →   3 →   4 →   5 →   6 →   7 →   0
```

该运行中，bit1的14次主要反向重组对应14个第二级进位门窗口与14次bit2翻转。丢弃前8个读窗后，48个稳态读窗仍全部正确；bit2低态窗最高S2约0.017，高态窗最低S2约0.978。

**这说明三级计数在选定确定性模型中成立；不等同于细胞实验已成功，也不保证共享资源反馈或随机噪声下仍然成立。**

### 4.5 Is it robust? — 结果是否依赖一个幸运初态

📈 **Figure 4-4 — Validation summary / 验证与边界**

| 检查 | 结果 | 说明 |
|---|---|---|
| 八种数字初态 | 8/8续跑600 h通过 | 初态来自稳定轨道的完整分子池，并统一上游相位 |
| 严格容差 | 5个代表点×3档，结论与码串一致 | 输出网格另行检查，泄漏积分需注明采样间隔 |
| 冻结前扰动 | 128次恢复原相位，8次合法相移，0失锁 | 8次相移来自翻转S2；谷点近零池的检验幅度有限 |
| 冻结后补充 | 30次有效扰动均恢复，另有6次对照 | 三类位于门内附近，三类提前29–41 h施加 |

这些测试支持规定初态、时间范围和扰动下的计数鲁棒性，不能转写成单细胞成功率或“所有相位、所有噪声都能恢复”。

### 4.6 Engineering — 模型怎样指导下一步构建

| 阶段 | 本项目做了什么 |
|---|---|
| Design | 用DNA重组记录状态，用I1-FFL把状态变化转换成进位 |
| Build | 接入真实C31通量，建立34／51状态ODE和显式表达链 |
| Test | 检查码串、进位对应、初态、扰动和数值收敛 |
| Learn | 正确计数需要时序匹配；门峰值或总剂量不能单独解释成败 |
| Decision | 冻结两比特前缀；三级选择独立n_A1_gate=6，下一步标定门响应和分子量级 |

与shutdown的接口应输出PB/LR状态及BM3R1的完整T(t)轨迹。shutdown读取BM3R1衰减来延迟sRNA启动，并清除output mRNA；联合模型、生长条件统一及启动子滴定尚待验证，不画成已完成的反馈闭环。

### 4.7 Scope and next steps — 已证明什么，还缺什么

当前已证明的是：选定连续ODE能够稳定完成两比特和三比特计数。参数换算、表达成熟时间及n=6的元件实现仍待实验标定；曾表gamma已包含稀释，但与上游50 min倍增条件尚未对齐。

当前模型未包含完整宿主资源反馈或分子随机性验证。可辨识性初版未通过审核，暂不引用参数可辨识、灵敏度排名或相关性结论。完整方程、参数来源、历史扫描、代码版本和复现材料放入Methods／补充材料。
