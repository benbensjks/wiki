## 脚本内断言（任一不成立即中止）

1. 保存轨迹重分析必须复现 `certified_v1 = True`、19 个稳态读窗、码串 `1234567012345670123`、裕量 1.1784609018563117 h。
2. 窗口必须恰好含 **2 次低位进位、1 次高位进位、1 次 bit2 翻转**；`J_rev1` 峰列表必须与 `S1` 下降沿列表一致。
3. 两次 g0 开启时 bit1 必须分别是 **LR** 与 **PB** —— 这是"第二次门开了却没有翻转"这条标注的依据，已用轨迹查证（`S1 = 0.9774` / `0.0143`）。
4. 渲染后文字包围盒越界数必须为 **0**（当前两版均 0 处）。

## 方向约定（第一版曾在此出错）

`S0 = b0_S`、`S1 = 1 - pb1_zmh` 都是 **LR 占比**。一次进位是位从 **LR→PB**，即该信号**向下**穿越 0.5。
认证表的 `flip_h` 记录的是**每一次** 0.5 穿越（向下和向上交替），所以只有 `flip_direction == "down"` 的行才是进位 —— 用它算出的铰链时刻与 `J_rev1` 峰一致。

## 刻度约定

- `g0` 与 `g1` **共用 [0, 0.68]**，`Int1` 与 `Int2` **共用 [0, 3.05]** —— 两级可直接对读门强与产物量（窗内实际峰：g0 0.629 / g1 0.387；Int1 2.716 / Int2 2.758）。
- `A/F` **按各自窗内最大值归一化**（A0 峰 1.905 对 F0 峰 6.422，差 3.4 倍；A1 1.360 对 F1 2.360，差 1.7 倍），**绝对值写在该行图例的斜杠后**。

## 图要传达的两个结论

1. **"快激活、延迟抑制"错开多久**：A 越过半峰 → F 越过半峰，
   **stage 0（ZMH 约化 A0/F0，直接蛋白方程）= 0.950 h**；
   **stage 1（HBY A1/F1，带 mRNA→成熟链）= 1.467 h**，**长 54%**。这是两个末级结构差异的直接可视证据。
2. **为什么持续 DNA 电平只产生一次进位**：窗内两次 bit0 进位里只有一次传播到 bit2。第二次 g0 在 138.000 h 开启时 bit1 已经是 PB（`S1 = 0.0143`），必须再正向前进一次才能反向，所以下一次 bit1 LR→PB 要等到 **159.636 h**。这就是第二级节律恰为第一级一半的原因。
