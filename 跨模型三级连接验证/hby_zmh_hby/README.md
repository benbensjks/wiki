# HBY bit0 → ZMH bit1 → HBY bit2

日期：2026-09-27。这是新路线，原27态路线与原冻结模型不变。

## 结构和单位

11态HBY bit0 + 2态ZMH A0/F0 + 4态ZMH bit1 + 6态HBY A1/F1 + 11态HBY bit2 = **34态**。这与历史34态二位模型仅维数相同，状态布局、模块和用途完全不同，不能混用索引/验证器。

连接：实际 `1-S0` 驱动曾同学A0/F0，产生Int1；曾同学实际PB1驱动我们的第二级carry；时钟门读取本路线的Int0。bit1仍用《完整二级级联.py》独立参数、无mRNA/显式复合物的约化方程。曾方程速率整体由每分钟换成每小时。

第二级沿用 n_gate=6，F1产生指数4，clock=.3/2，clock_scale=1；没有进行调参。a.u.尺度的接口假设仍未物理标定。下游不额外加稀释不等于细胞不生长。

### 两组输入

- **方波**：采用曾文件被注释的方波时序，首次5h、周期10h、宽100min，周期延拓至300h；幅度明确取HBY旧表目标产生速率6 a.u./h，经过mRNA/成熟层。不是采用曾文件的6 a.u./min。为避免漏积分边沿，在每个开/关点分段积分。
- **韩上游**：make_reference_parameters，零额外资源负担。HBY bit0的M_I就是C31共享mRNA；由韩上游启动子驱动，按实际C31翻译进入未成熟Int0，uM_per_au=5.75。不归一化蛋白浓度，不额外乘k_int，不增加第二个mRNA滤波层。五十分钟倍增与下游总清除率的生长条件一致性仍待实验澄清。

两个输入不是等剂量/等峰值对照；不能把结果差异全归因于波形形状。

### 方波的x不能当作动力学失败

原读法在相邻Int0峰间找最低点，并用总宽20%周期的对称窗口。方波Int0持续衰减到下一次方波开启，谷点正好在下一次输入开启附近。

第一个窗口中心15h，范围约14–16h；bit0在15.612h穿越0.5。它把新一次转换纳入了前一次读取，因此bit0占据率仅0.752<0.8。其余两个位在这些窗口均有确定标签。

保留原失败结果后，另做**事后诊断**：以每次方波关闭至下一次开启的OFF段中点为中心，总宽仍为20%周期，不做相位扫描。得到27个读窗：

`12345670123456701234567012345`

最小占据率1.0。这支持电路在该方波下实际能够计数，但不等于原谷值规则通过，也不作为重新命名的正式认证。下一轮应预先确定适合方波的读法，在独立运行中验证。补充结果与图在`follow_up_analysis/`，没有覆盖原读窗或原图。

### 事件顺序补充

两组中，按DNA穿越0.5定义的每次低位回零，均在下次回零之前对应一次高位翻转；无未分配高位穿越，高位翻转方向交替。韩组14次bit0回零→14次bit1翻转；7次bit1回零→7次bit2翻转。方波分别15→15、7→7。

这只是DNA事件层的配对，最后时间段有右边界截断；尚未核对门窗口及通量方向，所以不声称完成原项目的完整因果认证。
