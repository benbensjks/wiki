# 给 dsh 的交接：混合三级模型的参数版本与现有结论

日期：2026-09-28。本文是当前主结果的上下文，不是新运行。详细逐项参数见同目录 `主结果_完整参数与来源.md`。

## 先读：一句话版本

当前主结果是 **HBY bit0 → ZMH 现行 Python 参数的 A0/R0＋bit1 → HBY A1/F1＋bit2**。韩亚轩 v53d 上游输入下，34 状态模型在300 h内得到连续模8读出，并通过为此结构新建的确定性读窗和两级进位因果判据。ZMH 的 PDF 参数已经过时，不能用它替换主结果的中间位，更不能说整个混合模型的所有位都采用了现行 Python 参数。

## 三个参数身份必须分开

1. **ZMH 现行模块**：`wiki任务/完整二级级联.py` 的 A0/R0＋bit1；原文件同时有 bit0 和五状态上游，但主模型没有使用其 bit0 和上游。源 SHA256 `E790743F493F415E43296CD10911BB6C2A4E5A024F70E807A40267E9705A0E2B`。这里的速率原按分钟写，混合方程中乘60变成每小时。
2. **HBY 两端及第二级 carry**：HBY bit0、A1/F1、bit2 的基础数值来自 `final_reconstruction/model.py` 中的早期 PDF 参数表，再加表达、成熟和显式 Int–RDF 复合物扩展；第二级门指数为独立新增 `n_A1_gate=6`，F1产生指数仍为4。`model.py` 源 SHA256 `256D2D104EECB4CE17F27CF4DBC08257BEEEA79E5805FD7D5614E47BBC7E543A`。这些两端参数并未被迁移到 ZMH 现行 Python 值。
3. **上游输入**：韩亚轩 v53d `Flux_Driven_Translation_Burden_Model.py` 的参考参数，`peak_load_fraction=0`；bit0共享其 C31 mRNA，实际翻译通量进入未成熟 Int0。源 SHA256 `456326A418C4C7EE23C75FA2DD4A86070F37CAF820B5F863BBAA44FE9DCE51BD`。本路线不使用 ZMH 归一化 C31 蛋白浓度作为上游输入。

当前主代码 `hby_zmh_hby/model_hzh.py` 源 SHA256 `AD41B3E4C0681609BBB146406AFF28E6E27D87598080C9650EA5F296FEF0FA0A`。文件归属：11态HBY bit0、2态ZMH A0/F0、4态ZMH bit1、6态HBY A1/F1、11态HBY bit2，共34态。**不要**把它与历史34态二位模型按索引混用。

## 应引用的主结果

原运行：`results/20260927_233646_924908/han/`，300 h、1 min输出。

- 27个完整读窗，码串 `123456701234567012345670123`；drop8后19个读窗继续逐拍模8加1；全部读窗、全部三位的最小commitment=1.0。

- setup/hold最小值：bit0 5.962/1.178 h，bit1 6.875/1.301 h，bit2 6.117/2.221 h。全局受限项是 **bit0 hold≈1.178 h**。

## 两组历史结果怎样引用

`pdf_parameters/results/20260927_235006_013973/` 是将**过时 PDF 的21个表列参数**放回中间ZMH模块的回退实验，20个值相对现行代码发生改变。它在韩上游下bit0/bit1/bit2翻转29/5/1次，定位到中间位不能稳定回零。其作用是展示版本敏感性；它不是现行ZMH模型的失败证据，也不能由整组替换推断某个单独参数为根因。原方程结构没有因该回退而改变，不能声称此实验单独证明“结构不匹配”。

历史51状态扩展模型的 `ZENG` 基础表来自早期PDF。它在自己所记录的基础表、表达层、复合物及接口假设下取得的数值结论仍然是有效的**条件性模型结果**。现在要更正其参数**来源描述**：不能叫“曾同学现行Python版参数”，也不能仅凭组内PDF/注释叫“已发表测量参数”。不要直接把ZMH现行数值覆盖 `model.py:ZENG`，否则历史34/51态结果与哈希不再匹配。

方波的现行混合模型也是300 h；其原谷值读窗全`x`，因方波开启时刻与谷值窗口重叠。另一个OFF段中点读出连续模8，是**事后诊断**，须与原读窗结果一起披露，不属于韩上游主认证。方波与韩上游的bit0时钟峰值/占空也不相同，不构成单纯输入波形形状的等剂量对照。

## 剩余边界与 dsh 接手要求

- 各模块 a.u. 标尺尚未共同实验标定，bit0通量换算采用 `uM_per_au=5.75`，第二级clock读取本路线的成熟游离 bit0 Int0，clock K/n=0.3/2；不能替换成ZMH外部 `int0` 后仍保持同一工作点。
- 韩上游Td=50min对应增长稀释≈0.832/h，下游表中有总清除率0.6/h；相同细胞生长条件的物理一致性尚未解决。`add_growth=False` 表示不额外重复计入稀释。
- 当前结果没有参数分布鲁棒性、随机噪声、元件实体标定或湿实验成功率。读窗commitment=1.0是此判据上限，不是噪声胜率。
- 若为Wiki取图，优先 `results/20260927_233646_924908/han/overview.png`；图注必须标“ZMH现行Python参数的中间位＋HBY两端”，并引用上面的新结构认证。
- 不修改既有结果或全局ZENG后仍引用旧哈希。新实验需独立参数文件、源SHA256与验证判据版本。
