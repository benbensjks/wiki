# 手绘流程示意图指南：混合三级计数器（34 状态）

**对象**：`跨模型三级连接验证/hby_zmh_hby/model_hzh.py`，即 **HBY bit0 → ZMH 现行 A0/F0＋bit1 → HBY A1/F1＋bit2**，300 h 韩上游模 8 认证模型。韩上游先单独求解，再以单向插值输入驱动这套 34 状态接收模型。

**本文的用法**：这是一份**手绘施工图**。按 §2 的三轮回画顺序动笔，用 §3 的元件总表决定"画哪些方块"，用 §4 的箭头总表决定"连哪些线"，§5 给版面坐标，§6 给线型语言的纸面等价物，§8 是三个最容易画错的地方，§9 是画完对着打勾的自检表。

**每一条分子机制箭头都应能在源码 RHS 中找到对应项**，出处见文末附表。读窗、阈值和认证属于轨迹后处理，不是 RHS 中的生化反应。凡本文与源码冲突，以源码为准。

> ⚠️ **口径必须写进图注**（交接文档明文要求）：**"ZMH 现行 Python 参数的中间位 ＋ HBY 两端"**。不能说"全部采用曾同学现行参数"。

## 1 先记住：这张图要回答什么

一句话：**"每来一个时钟周期，哪一个分子驱动了哪一次翻转；进位是怎么从低位传到高位的。"**

所以这是一张 **接线图（wiring diagram）**，不是数据图、不是结构域图。它要能让人**顺着箭头走完一次进位**。

**必须能一眼看出的五件事**：

1. 上游振荡器是**单向耦合的驱动子系统**，不在 34 状态接收向量中（34 态里不含 TetR/CI/LacI）；“范围框外”不等于生物学上与电路无关
2. bit0 的整合酶是**上游真实翻译通量**喂的，不是门喂的
3. carry0 与 carry1 都是 **I1-FFL**（激活臂 + 抑制臂），但**只有 carry1 有时钟 AND 门**
4. bit2 的时钟读的是 **bit0 自己的成熟游离 Int0**（一条回绕线）
5. bit0 / bit2 是**显式复合物**（有 `C` 态），bit1 是**约化乘积式**（没有 `C` 态）

## 2 三轮回画顺序（不要一次画完）

### 第 1 轮：只画 7 个方块 + 6 条主链（30 分钟）

不写任何参数、不画任何分子细节，只求拓扑对。

```
[1 韩上游 repressilator + C31 mRNA]   ← 画在“34态接收向量”框外（单向驱动）
        │ 共享 C31 mRNA ／ 翻译通量
        ▼
[2 bit0 · HBY 11 态] ──反重组──▶ [3 carry0 · ZMH A0/F0] ──Int1──▶ [4 bit1 · ZMH 4 态]
                                                                        │
[6 bit2 · HBY 11 态] ◀──u2：Int2 表达源── [5 carry1 · HBY A1/F1] ◀──LR→PB 回零──┘
        │                                  ▲
        └──── 成熟游离 Int0 ──clock AND ────┘        ← 回绕线，全图最关键的一根
─────────────────────────────────────────────────────────────────
[7 读出：Int0 谷值窗]
```

**第 1 轮的验收标准**：这 6 条主链画完后，纸上**没有线交叉**。如果交叉了，说明第 6 块（bit2）该放到右下而不是左下，先调位置再往下画。

### 第 2 轮：把 carry 和位内部展开（1–2 小时）

- carry0 与 carry1 展开成 **A 臂 + F 臂 + AND 门**（§4 的 C-1…C-5、D-1…D-8）
- bit0 与 bit2 展开成 **三条子链**（整合酶 / RDF–Rep 环 / 重组反应），见 §3.2
- bit1 展开成 **2×2 小方块**（它只有 4 个状态，不要照抄 11 态的画法）

**第 2 轮的验收标准**：能指着图说"这次进位经过了哪 5 个分子"。

### 第 3 轮：加标注（1 小时）

- 门旁边写 `K` 与 `n`（§4 每行都给了）
- 复合物旁边写 `k_on / k_off / δ_C`
- 三个来源身份用三种底色或三种阴影（§6.3）
- 图例 + 图注（§9）

### 3.1 模块切分（7 块）

| 3 | carry0（ZMH A0/F0） | **2** | `A0_zmh, F0_zmh` | 曾同学现行 Python 代码 | 是 |

| 5 | carry1（HBY A1/F1） | **6** | `A1, F1, M_A1, A1_u, M_F1, F1_u` | HBY 早期基础表 | 是 |
| 6 | bit2 | **11** | `b2_M_I, b2_I_u, b2_I, b2_M_T, b2_T_u, b2_T, b2_M_R, b2_R_u, b2_R, b2_C, b2_S` | HBY 早期基础表 | 是 |
| | **合计** | **34** | | | |

> **上游不属于这套34态接收向量。** `model_hzh.py` 从预先解好的上游轨迹插值出启动子活性 `h31(t)`，34 个状态里没有 TetR/CI/LacI。画图时把上游画在**蓝灰虚线范围框之外**，用单向箭头表示驱动。这里的状态数为 `11 + (2+4) + 6 + 11 = 34`：bit0 11态、ZMH中间模块6态、carry1 6态、bit2 11态。
>
> carry0 的 2 态与 bit1 的 4 态**合起来**才是交接文档所说的"2 态 ZMH A0/F0 ＋ 4 态 ZMH bit1"。

### 3.2 每个 HBY 位（bit0 / bit2）的三条子链

bit0 与 bit2 用**同一套 11 态模板**，画法完全一样，只是驱动源不同：

| 子链 | 分子 | 画法 |
|---|---|---|
| **整合酶链** | `M_I`（mRNA）→ `I_u`（未成熟）→ `I`（成熟游离整合酶） | 三个小方块串成一条，箭头向下 |
| **RDF–Rep 环** | `M_T/T_u/T`（Rep=BM3R1）与 `M_R/R_u/R`（RDF） | 上下两个小三角，`T` 用 T 形头抑制 `R` 的表达 |
| **重组反应** | `S`（LR 比例），`PB = 1 − S` | 画成一个圆，旁边写 `S`；正向进 LR，反向回 PB |
| **复合物** | `C` | 画成 `I + R ↔ C`，并从 `C` 画一条清除箭头到 `∅`，标 `δ_C` |

### 3.3 两条驱动源（bit0 与 bit2 唯一的不同）

| | bit0 | bit2 |
|---|---|---|
| `M_I` 的产生源 | **上游 C31 启动子转录活性** `h31(t)`<br>源码：`tx = 60·N₀·c31_tx·h31(t)/copies_per_au` | **carry1 门输出** `u2 = 38·g1`（目标成熟产生速率） |
| `M_I` 的清除 | **上游 C31 mRNA 的总损失** `60·(c31_mrna_intrinsic_loss + μ)` | 本位的表达链 mRNA 损失 `λ_m` |
| `I_u` 的产生源 | **上游 C31 翻译通量** `60·0.5·M_I` | 本位的 `translation_h·M_I` |
| 时钟 | 上游振荡本身 | `clock = H(b0_I; 0.3, 2)` |

> ⚠️ **这里是最容易搞错的一处**：**转录**（启动子活性）喂的是 `M_I`，**翻译通量**喂的是 `I_u`。交接文档那句"bit0 共享其 C31 mRNA，实际翻译通量进入未成熟 Int0"说的正是后一件事。图上如果只画一根"上游 → bit0"的箭头，要在旁边分开标"转录 → `M_I`"和"翻译 → `I_u`"。

### 3.4 bit1 只有 4 个状态（**不要**照抄 11 态画法）

| 状态 | 含义 | 产生源 | 清除 |
|---|---|---|---|
| `pb1_zmh` | PB 构象**比例**（直接积分，不是 `1−S`） | —（由重组通量 `−vf + vr` 决定） | — |
| `I1_zmh` | 成熟整合酶 | `α_Int1 · H(A0; 1.0, 2) · G(F0; 2.6454, 5.4332)` | `γ_int1 = 4.8 /h` |
| `T1_zmh` | Rep（BM3R1） | `α_rep1 · PB1` | `γ_rep1 = 0.3 /h` |
| `RDF1_zmh` | RDF | `α_rdf1 · LR1 · 1/(1 + (T1/1.8)³)` | `γ_rdf1 = 0.3 /h` |

**没有 mRNA、没有未成熟态、没有 `C` 复合物态** —— 这三点要在图上留白，并注明"约化模块"，不要补。

## 4 箭头总表（决定"连哪些线"）

线型代号：**→** 激活/产生 ｜ **⊣** 抑制 ｜ **↔** 可逆结合 ｜ **⊗** AND（因子在圆圈处相乘）｜ **⇢** 未建模/假设

### 4.1 上游 → bit0

| # | 从 | 到 | 型 | 源码依据 |
|---|---|---|---|---|
| U-1 | 上游 C31 启动子活性 `h31(t)` | `b0_M_I` | → | `tx = 60·N₀·c31_tx·h31(t)/copies_per_au` |
| U-2 | `b0_M_I` | `b0_I_u` | → | `translation = 60·0.5·M_I` |
| U-3 | `b0_I_u` | `b0_I` | → | `d[b0_I] = km·I_u − γ_int[0]·I − bind + un` |

> ⚠️ **`b0_M_I` 就是上游那份 C31 mRNA 本身**，不是它的副本。图上只能画**一个** mRNA 方块，用双线边框或虚线套住表示"上游与 bit0 共享"。

### 4.2 bit0 / bit2 内部（两个位各画一份）

| # | 从 | 到 | 型 | 源码依据 |
|---|---|---|---|---|
| B-1 | `M_T` → `T_u` → `T` | | → | `expression(..., α_rep·(1−S), …)`，**PB 驱动** |
| B-2 | `M_R` → `R_u` → `R` | | → | `expression(..., α_rdf·S·(1−H(T; 0.85, 3.9)), …)`，**LR 驱动** |
| B-3 | `T` | `R` 的产生 | ⊣ | 上式中的 `(1 − H(T; K_rep, n_rep))`，`K_rep = 0.85`、`n_rep = 3.9` |
| B-4 | `I` + `R` | `C` | ↔ | `bind = k_on·I·R`，`unbind = k_off·C` |
| B-4a | `C` | `∅` | → | `dC` 中的 `−δ_C·C`；表示复合物清除，不表示 DNA 损失 |
| B-5 | `I` | 正向重组 | → | `vf = k_fwd·H(I; K_D_int, 2)·K_inh/(K_inh + R)` |
| B-6 | `R`（游离） | 正向重组 | ⊣ | 上式分母 `K_inh/(K_inh + max(R,0))` |
| B-7 | `C` | 反向重组 | → | `vr = k_rev·H(C; K_complex, 2)` |
| B-8 | 正向重组 | `S` 增（→ LR） | → | `dS = vf·(1−S) − vr·S` |
| B-9 | 反向重组 | `S` 减（→ PB） | → | 同上 |

> `C` 是**复合物**；`I` 与 `R` 的减少都汇到它。`K_complex = q·K_D_comp`，`q = k_on/(k_off + δ_C) = 0.05`。
> 注意 `C` 的清除是 `δ_C·C`（复合物降解），**不是** DNA 损失；`S + PB ≡ 1` 恒成立。

### 4.3 carry0（ZMH A0/F0）—— I1-FFL，**无时钟**

| # | 从 | 到 | 型 | 源码依据 |
|---|---|---|---|---|
| C-1 | bit0 的 PB（`1 − b0_S`） | `A0` | → | `dA0 = α_A0·(1 − b0_S) − γ_A0·A0` |
| C-2 | `A0` | `F0` | → | `act = H(A0; K_A0 = 1.0, n_A0 = 2)` |
| C-3 | `A0` | `I1` | → | 同一个 `act` |
| C-4 | `F0` | `I1` 的产生 | ⊣ | `gate = G(F0; K_R0 = 2.6454, n_R0 = 5.4332)` |
| C-5 | `A0` ⊗ `F0`-gate | `I1` | ⊗ | `α_Int1 · act · gate`，`α_Int1 = 22.728 /h` |

**画法**：`A0` 出发两条线 —— 一条**直接**去 `I1`（激活臂），一条经过 `F0` **绕一圈**再去 `I1` 并抑制它（抑制臂）。这就是 I1-FFL 的标准形状。

### 4.4 bit1 → carry1（HBY A1/F1）—— I1-FFL **＋ 时钟 AND**

| # | 从 | 到 | 型 | 源码依据 |
|---|---|---|---|---|
| D-1 | `pb1_zmh` | `A1` | → | `sa = α_A[1]·pb1·(1 − H(A1; K_auto1 = 0.6, n_auto1 = 2))` |
| D-2 | `A1` | `A1` 自身 | ⊣ | 上式的 `(1 − H(A1; 0.6, 2))` —— **负自馈** |
| D-3 | `A1` | `F1` | → | `sf = α_F[1]·H(A1; K_A[1] = 1.2, n_A[1] = 4)` |
| D-4 | `A1` | `g1` | → | 参考工作点为 `H(A1; 1.2, **6**)`；这里的 6 是独立门指数，不是 F1 产生臂的指数 4 |
| D-5 | `F1` | `g1` | ⊣ | `(1 − H(F1; K_F[1] = 0.4, n_F[1] = 4))` |
| D-6 | **`b0_I`** | `clock` | → | `clock = H(clock_scale·int0; 0.3, 2)`，`int0 = y[b0_I]` |
| D-7 | `A1` ⊗ `F1`-gate ⊗ `clock` | `u2` | ⊗ | `u2 = α_Int[1]·g1 = 38·g1`（a.u./h，**目标成熟产生速率**） |
| D-8 | `u2` | `b2_M_I` | → | 经表达链 `source·λ_m/translation_h` 进入 `b2_M_I` |

**画法**：`g1` 的 ⊗ 圆圈要有**三条入线**（A1 激活、F1 抑制、clock 激活）；`g0` 的 ⊗ 只有**两条**。这个扇入数差别就是"两级结构不对称"的图形证据。

> ⚠️ **D-6 是全图最容易画错的一根线**。`clock` 读的是**本路线 bit0 的成熟游离 `b0_I`**，**不是** ZMH 外部的 `int0`。而且这条线是**回绕**的：从图左边的 bit0 绕到右边的 carry1。手绘时留一条沿图底或图顶的通道。
>
> `clock_scale` 与 `clock_K_au` 在该 Hill 项中只以比值 `clock_K_au/clock_scale` 出现，数学上不是两个独立自由度。图上写完整公式即可，不要把二者画成两个串联的生化元件。
>
> **`n_A1_gate=6` 是当前参考工作点，不是混合模型成功的必要条件。** 最新混合模型扫描中，基线附近已测 `n=3–8` 均可连续计数；提高 `n` 主要改善 bit2 时序裕量，并提高对 `K_A[1]` 偏移的容忍度，没有移动 `uM_per_au` 的计数边界。因此图中可以标“reference: 6”，不要写“required: 6”。

### 4.5 输出与读出

| # | 从 | 到 | 型 | 说明 |
|---|---|---|---|---|
| R-1 | `b0_I` | 读出窗定位 | → | 读窗 = Int0 **相邻峰之间的谷值**为中心，两侧各取 10% 峰间距 ⇒ 总宽 = 时钟周期 **20%** |
| R-2 | 三位 DNA | 数字 | → | **读的是 `S0 = b0_S`、`S1 = 1 − pb1_zmh`、`S2 = b2_S`** |
| R-3 | 窗内标签 | 位值 | → | `S ≤ 0.30` 占比 ≥80% 记 **0**；`S ≥ 0.70` 占比 ≥80% 记 **1**；否则该窗记 `x` |
| R-4 | 三位标签 | 读数 | → | `value = S0 + 2·S1 + 4·S2`（**bit0 是最低位**） |

> ⚠️ **极性陷阱**：`pb1_zmh` 是 **PB**，而 bit0/bit2 用的是 **`S`（LR）**。验证器在读出前**显式做了 `S1 = 1 − pb1_zmh`** 的换算，所以三位才共用同一条 `≤0.3 / ≥0.7` 判据。图上如果直接拿 `pb1` 去贴 `S ≤ 0.3 → 0` 的规则，方向就反了。
>
> 稳态另需丢弃**前 8 个**读窗，且剩余 ≥16 个窗；两级进位链各自丢弃**前 2 个**进位事件作烧入。
>
> 图中的 `0.30/0.70` 是 DNA 数字读出的带阈值。认证程序使用的 `J_rev=0.1 /h` 与 `gate=0.05` 是**事件分段阈值**，对轨迹的切段结果可能敏感，不能画成启动子或分子的物理阈值。若图中不展示验证流程，建议完全省略这两个数。

## 5 版面坐标（纸上网格）

建议 **A3 横放**，划 5 列 × 3 行：

```
列   →    1          2            3            4            5
行1     [上游振荡]                                            [图例]
行2                [bit0 11态]  [carry0 2态]  [bit1 4态]
行3     [读出窗]   [bit2 11态]  [carry1 6态]  ←── 时钟回绕通道 ──
```

**具体建议**

- 第 2 列放 bit0（上）与 bit2（下）—— 它们是同一套 11 态模板，**上下对齐画，形状完全一致**，读者一眼能看出"两端同构"
- 第 3 列放 carry0（上）与 carry1（下）—— 同样上下对齐，**只在 carry1 上多加一条 clock 入线**，差异自证
- 第 4 列放 bit1（上，它只有 4 个状态，方块可以小一点）
- 时钟回绕线走**图底**，从第 2 列下方拉到第 3 列下方
- 上游画在**范围框外**；图例放右上角；§9 的图注放图下方

**留白**：每块四周留 1 格，第 3 轮加标注时要用。

## 6 线型语言（纸面等价物）

### 6.1 七类线与符号

| 含义 | 纸上画法 |
|---|---|
| 抑制 | 实线 + **T 形端头** |
| 激活 / 产生 | 实线 + **实心箭头** |
| 可逆结合 | **双向箭头**（`<──>`） |
| AND | 实心圆 + 圆内写 **×**，各因子线汇到圆上 |
| 读出带阈值 | **橙色虚线**横线（只用于 `S=0.30/0.70` 等读出说明） |
| 模型范围 | **蓝灰虚线**圆角框 |
| 未建模耦合 | **空心虚线箭头** |

### 6.2 主色与辅助色（与项目其它图一致）

| 颜色 | 十六进制 | 用途 |
|---|---|---|
| 深蓝 | `#304B53` | 结构、DNA 状态、抑制 |
| 橙 | `#D29144` | 时间、阈值、风险、强调 |
| 蓝绿 | `#4F9194` | 重组酶、结果、已通过路径 |
| 蓝灰 | `#8CA0A5` | 范围框、未建模 |
| 墨 | `#33383A` | 正文 |

## 8 三个最容易画错的地方

### 8.1 时钟不是总线

现有总览图 `fig07_full_system_coupling` 把 clock 画成**接到三个位的共享输入**，这对本模型是**错的**：

| 位 | 时钟来源 |
|---|---|
| bit0 | 上游 C31 转录活性 / 翻译通量（振荡本身） |
| bit1 | **没有时钟**，`g0` 只有两项 |
| bit2 | `g1` 的第三因子，读 `b0_I` |

照抄那张图会画出一条不存在的线。

### 8.2 两级 carry 的门不对称

| | carry0（`g0`） | carry1（`g1`） |
|---|---|---|
| 因子数 | **2** | **3** |
| A 臂 | `H(A0; 1.0, n=2)` | `H(A1; 1.2, n=**6**)` |
| F 臂 | `G(F0; 2.6454, n=5.4332)` | `G(F1; 0.4, n=4)` |
| 时钟 | 无 | `H(b0_I; 0.3, 2)` |
| 指数是否解耦 | 两个臂各用表值，**无独立门指数** | **门臂 6 与 F1 产生臂 4 解耦**（`n_A1_gate` 是独立参数） |

**别把两级画成对称的。** 扇入 2 vs 3 是图形证据；`n = 6 vs 4` 的解耦要在 carry1 旁单独标注。同时注明“6为参考工作点”，不要把它画成不可改变的分子结构或六个结合位点。

### 8.3 bit1 是约化位，不是 11 态位

| | bit0 / bit2 | bit1 |
|---|---|---|
| 状态数 | 11 | **4** |
| 表达链 | `M → u → I` 三层 | 无，直接积分成熟 `I1` |
| 复合物 | 有 `C`，`I`、`R` 双向结合 | **无**，反向用乘积的 Hill |
| 构象 | `S`，`PB = 1 − S` | `pb1` **直接积分**（不是 `1 − S`） |
| 正向 | `k_fwd·H(I; K_D_int, 2)·K_inh/(K_inh + R)` | `k_fwd·pb1·H(I1; 1.8, 4)·Kinh/(Kinh + RDF1)` |
| 反向 | `k_rev·H(C; K_complex, 2)` | `k_rev·(1−pb1)·(I1·RDF1)²/(3.2² + (I1·RDF1)²)` |

画的时候 **bit1 用 2×2 的小方块**，并在旁边注明"约化模块，无复合物态"，别让读者以为是漏画。
