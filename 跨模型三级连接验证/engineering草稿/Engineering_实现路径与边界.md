## 9.4 工程实现路径与边界 (Implementation Path & Boundaries)

> 本节说明**从已验证的模型功能走向实验元件时需要逐层确认什么**。近期实验目标是**单个 DNA bit 的可测实现**，进位模块与三位级联为分阶段扩展。

### 9.4.1 近期目标：单个 DNA bit 的双向切换

模型中的 $S_i$ 表示 LR 状态比例，因此实验应**直接检测 DNA 位点的重组状态**，并辅以报告信号观察输出。报告蛋白的表达与成熟会引入额外延迟，**不能单独以荧光变化代替 DNA 翻转时间**。

单 bit 阶段需分别表征三件事：

1. **正向写入**（PB→LR）；
2. **RDF 参与的反向复位**（LR→PB）；
3. **两次输入之间的状态保持**。

应记录每次输入的**强度、持续时间、翻转完成时间与残余表达**，才能判断模型中的输入脉冲与实际细胞响应是否对应。ϕC31 整合酶及其 RDF 已有正反向重组的实验依据，但具体构建中的表达水平、剂量与宿主条件仍须测定。

### 9.4.2 第二阶段：bit0 回零接入 A0/F0 前馈环

这里要验证的是：**持续的 PB 状态是否实际形成一次有限的 Int1 表达脉冲**，以及**脉冲尾部会不会在非进位时继续作用**。

$A_0$/$F_0$ 在模型中仍是具有指定激活、抑制功能的**抽象因子**；选定实体元件后需测量其响应曲线与时间常数，再判断能否近似模型中的有效门函数。这也是本阶段的主要不确定来源。

### 9.4.3 第三阶段：A1 负自馈与主时钟 AND 门

模型选择的 `n_A1_gate = 6` 是**有效响应陡峭度**，不代表已设计出六个结合位点或确定了具体启动子。

需要说明该陡度在模型中的位置：它落在**单个 Hill 项**上（$H(A_1;K_{A,1},6)$）。若把这一项字面理解为单一启动子上的协同结合，则有效陡度不可能超过结合位点数，即需要不少于六个协同位点；**但这一解读并非唯一可能**——同等的有效陡度也可以来自多级 Hill 串联、零级 ultrasensitivity，或杂合启动子／拆分整合酶等结构。**模型没有证明上述任何一种实体实现不可能**；可以确认的只是：**该陡度的实体来源尚未确定，属下一阶段的开放项**。

无论采用哪种实现，都必须分别验证门的**关态、开态与时序**，才能与模型结果对应。

### 9.4.4 多位正交扩展属调研阶段

ϕC31、Bxb1、TP901-1 等系统可作为多位正交重组的**候选**；已有研究在**特定宿主与构建**中展示了多种整合酶的共同使用。但整合酶识别位点的正交性**不自动**证明配套 RDF 不会交叉作用，也不证明这些系统能在本计数器中以相同速率完成双向切换。因此多位实体组合仍需逐一验证重组、复位与相互串扰。

> **表述纪律**：上述整合酶与阻遏蛋白名称在本阶段**列为调研候选，不表示已由实验组确定**。凡引用文献，须在参考文献表中标注其**宿主与体系**（哺乳动物 / *E. coli* / 无细胞），避免以其他宿主体系的结果支持本项目的构建结论。

### 9.4.5 模型与实验对接需统一的两件事

1. **换算标尺**：当前 `uM_per_au = 5.75` 是**未标定的换算假设**。它不只是把 a.u. 重标成 µM：该旋钮经 `copies_per_au = 602.214076 × uM_per_au` 直接缩放 bit0 的 Int0，从而平移时钟门 $H(\mathrm{Int}0;0.3,2)$，**改变的是工作点本身**——产物记录显示改它会使 a.u. 层面的池峰值不保持、FLAG 池清单发生变化（$uM\_per\_au = 5.5/5.75/6.5$ 下最大游离池为 41.07/42.94/48.54 µM，FLAG 池数 5/7/7），探针也显示 ±13 % 改动会移动时序裕量与门峰值。因此**"所有绝对浓度线性依赖它"只在该标尺变化而轨迹不变的换算意义上成立**；用它反推启动子强度与拷贝数还需要表达测量、细胞体积与构建信息，**它不是唯一通道**。
2. **生长条件**：下游总清除率已包含稀释，而上游采用的倍增时间为 50 min（$\mu \approx 0.832\ \mathrm{h^{-1}}$）；若解释为同一细胞生长条件，隐含本征降解率为负。两者必须在**同一实际培养条件**下核对。

**结论**：不能把模拟的 a.u. 数值直接解释为已测蛋白浓度；工作窗口只应表述为**模型可行域**，不是实验容差。

## 9.5 Engineering：Design → Build → Test → Learn

### 9.5.1 模型侧：已完成的四个阶段

**Round 1 — 定位到"第二级门写入不足"**

| 阶段 | 内容 |
|---|---|
| **Design** | 沿用基础表：$A_1$ 的 Hill 指数在同一槽位上被**两处**共用——一是促进 $F_1$ 产生，二是进位门 $g_1$ 里的 $A_1$ 臂（均为 `ZENG['n_A'][1] = 4`）；第一级 $A_0$ 的指数是另一个槽位（`n_A[0] = 2`），不受影响 |
| **Build** | 51 状态模型：上游 6 + 三个 11 态位 + 两级各 6 态进位表达链 |
| **Test** | 600 h 读窗解码 + 进位事件链因果检查 |
| **Learn** | bit0/bit1 正常，但 **bit2 仅 3 次阈值穿越**，正反通量逐周期抵消后停在高态。**失败定位在第二级门的写入不足，不在低位、也不在接收位**；同时暴露了"一个槽位两处使用"使效应无法归因 |
| **Decision** | 把门指数从共享槽位中**解耦为独立参数** `n_A1_gate`，只作用于 $g_1$ 的 $A_1$ 臂 |

**Round 2 — 解耦后重新选值：20 点配对网格**

| 阶段 | 内容 |
|---|---|
| **Design** | 用超周期配对泄漏指标 $L_{\mathrm{symmetric}}$ 在**已认证点之间**排序，取"已认证且位于平台内"的最小指数 |
| **Build** | 20 点网格：$n_{A1,gate}\in\{4,5,6,7,8\}$ × carry1 mRNA {2, 4} min × A1/F1 成熟 {32.5, 60} min；F1 产生臂固定为表值 4 |
| **Test** | 每点 600 h；尾部切分 1 % / 5 % / 10 % 三档全部报告 |
| **Learn** | $n=4$ → 0/4；$n\ge5$ → 16/16；排序 $8<7<6<5\ll4$ 在三档切分下一致；$n=6$–$8$ 构成平台（内部极差 1.29 倍） |
| **Decision** | 取 $n=6$——已认证且位于平台内的最小指数 |

> **关于"加长 vs 加陡"**：仓库中另有一轮 44 点两臂扫描，但其**归档记录明确标注其工作点是混合的**（臂 A 固定在历史表值 $n=4$，臂 B 改变 $n$），因此**不能作为"从同一基线比较两个旋钮"的同类对照**，其产物在冻结工作点上**不允许被引用**，脚本也禁止重跑。可以保留的只是**该配置下**的观察："在这些设置中延长成熟时间未恢复计数"。$n=6$ 的选择依据以**上一段的 20 点配对网格**为准。

**Round 3 — 泄漏指标的修订（两个成分）**

| 阶段 | 内容 |
|---|---|
| **Design** | 审计早期泄漏指标；被撤对象是**单窗口 `leak_ratio`** $= \mathrm{median}(\text{far\_off\_rev}) / \mathrm{median}(\text{gate\_on\_rev})$ |
| **Build** | 逐窗数据落盘（`carry_pairing/{kind}_windows_*.csv` 与 `_pairs_*.csv`），使重新聚合无需重积分 |
| **Test** | 同一电路三种初态复算；三档尾部切分 |
| **Learn** | **两个独立缺陷**：**(i)** 脉冲衰减尾部与远驻留期未分开，正常衰减被计入"持续泄漏"；**(ii)** bit2 每隔一次进位才被写入，连续进位呈 R/F 交替，而把两个**中位数相除**时若窗口数为奇数，比值会**落在单一 carry 型上**而不是落在两型之间——同一电路可产生约 $2.9\times10^6$ 倍的假差异；另有次生缺陷：分子取"可评估窗"的中位数、分母取"全部窗"的中位数，两者索引集不同 |
| **Decision** | 改为：一个 R 加一个 F 组成完整超周期；**先在对内求和、再跨对统计**，分子分母不再各自取中位数再相除；尾部单列并单独报告；三档切分全部给出。修订后在同样的八初态上，配对统计量的相对离散度约 **0.08 %** |

> **此项修订并不削弱 $n=6$ 的选择**——勘误记录的结论是"$n_{A1,gate}=6$ 仍为预选中心，且该修订**加强而非削弱**它"。另需注意：**早期指标并未全部退休**——51 态认证谓词中的 `contrast` 臂（门 on/off 峰值比）**仍然生效**，本次修订只涉及单窗口 `leak_ratio`；而 mod-8 认证、事件计数、承诺度与带边距离、setup/hold、结构前缀护栏与八初态读出**均不受该修订影响**。

**Round 4 — 跨模型混合连接（本合作的最终阶段）**

| 阶段 | 内容 |
|---|---|
| **Design** | 明确两个模型的接口，而不是比较孰优：**保留曾同学现行代码中的第一级前馈环与 bit1，两端使用本模型的 bit0 与 bit2** |
| **Build** | **① 时间统一**：曾同学模型按分钟积分，其速率换算为每小时（×60），两侧在同一小时时间轴上推进；**② 变量含义统一**：由 $S_0 = LR_0$ 提供 $PB_0 = 1-S_0$ 驱动 $A_0$，由 FFL bit1 的 $PB_1$ 驱动 $A_1/F_1$ 表达网络；**③ 时钟改接**：第二级时钟门读取**同一混合模型 bit0 的成熟游离 Int0**，不再使用外部归一化浓度；**④ 接入**：$A_0/F_0$ 把 bit0 回零转成 Int1 脉冲驱动 bit1，第二级门产生 Int2 目标产生速率后经完整表达链驱动 bit2 |
| **Test** | 300 h 连续运行（未通过搜索参数挑选结果）；进位**事件配对**（bit0 反向重组 → 第一级门 → bit1 翻转，以及 bit1 反向重组 → 第二级门 → bit2 翻转，各检查一一对应、顺序与方向交替）；**数值复算**（收紧积分容差、输出网格 1 min → 0.5 min）；**八个轨道初态**各自续跑 300 h |
| **Learn** | 27 个连续可判定读窗、三个位最小承诺度均为 1.0，丢弃首个完整模 8 周期后余 19 个读窗仍逐拍递增；事件链 **14 → 14 → 14** 与 **7 → 7 → 7**；八初态均读到预期的下一拍；判据为混合模型自建的 `HZH_MOD8_CAUSAL_V1`，**不使用也不继承** 51 态的认证谓词 |
| **Decision** | 把混合连接登记为**独立的模型线**：拥有自己的状态布局、参数版本、判据与认证记录；51 态的认证结论**不转授**给它 |

### 9.5.2 模型导致的改变

> 本节回答"模型是否改变了设计"。

| 模型发现 | 设计后果 |
|---|---|
| $n_A[1]$ 一个槽位两处使用，效应无法归因 | 门指数解耦为独立参数 `n_A1_gate`（只作用于 $g_1$ 的 $A_1$ 臂；F1 产生臂保持表值 4） |
| $n=4$ 下 bit2 无法完成反向写入 | 采用 $n=6$：已认证且位于平台内的最小指数 |
| 单窗口 `leak_ratio` 在奇数窗口下取中位数会落在单一 carry 型上 | 改为对内求和、跨对统计；分子分母不再各自取中位数再相除；尾部单列 |
| $\gamma$ 已含生长稀释 | `add_growth = False`，不再叠加稀释 |
| 浓度接口会重复计入 tag／稀释 | A→B 接口改为**翻译产生通量**（µM/h） |
| 两个模型各自只在"自己那一版参数表"上成立 | 跨模型连接必须先明确接口与时间/变量含义，并保留各自的参数版本记录 |
| $n_{A1,gate}=6$ 落在单个 Hill 项上 | 登记"陡度的实体实现尚未确定"为开放项 |

### 9.5.3 实验侧：分阶段实现路线

```text
第一层  bit0 DNA 正反翻转
        ↓ 需确认：DNA 重组状态、输入波形、翻转完成时间、状态保持时长、残余表达
第二层  A0/F0 产生一次进位脉冲
        ↓ 需确认：门开态峰值、关态残余、脉冲宽度、脉冲尾部在非进位期的作用
第三层  接入 bit1
        ↓ 需确认：一次回零是否只触发一次高位写入（一一对应、顺序、方向交替）
第四层  正交元件与第二级时钟门
        ↓ 需确认：正交性、双向切换速率、串扰；陡度的实体实现方式
        （作为后续多位构建目标）
```

**每层都必须独立验证后再叠加。** 需要区分两件事：**前级右端不依赖新增高位，是所选无反馈结构的性质**（前 34 维的导数由冻结两位模型本身给出，因此结构上不可能依赖 bit2）；而**独立积分得到的轨迹一致是数值结果**（有限容差下的轨迹差，不要求逐位相等）。前者不能替代实验上"加一级不破坏前一级"的验证，后者也不能被当作该结构性质的证明。

## 附 D：本节明确**不**主张的事项

1. 不主张三位电路即将整体构建——实验近期只能做到 bit0；
2. 不主张模型给出的 300 h 或 600 h 确定性计数结果等价于湿实验成功率；
3. 不主张任何具体整合酶／阻遏蛋白组合已在本项目宿主中搭配验证；
4. 不主张"杂合启动子"或"拆分整合酶"在参数容忍度上优于对方——模型比较的是**门指数取值**，不是这两种物理实现；也不主张某种实体实现已被证明不可能；
5. 不主张 51 状态模型与混合模型的认证可以互相转授——两者参数版本、状态结构与验收判据均不同。
