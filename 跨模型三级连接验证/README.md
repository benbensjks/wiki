# 跨模型三级连接验证：初步代码

这里是新建的独立实验目录。原有模型、参数和权威清单不作修改。

## 当前结构

曾同学的振荡器（预积分五状态，归一化 C31 蛋白浓度）→ 原十状态低两位 → hby 六状态 A1/F1 → hby 十一状态 bit2。

主积分为 **27 状态**，时间统一为小时。原十状态的 RHS 原样从 hash 固定的 `wiki任务/完整二级级联.py` 中提取声明；没有执行其顶层积分和绘图。分钟导数整体乘60，查询原输入时使用60*t_h。

原文件只有第一级 A0/R0，第二级网络由 hby 提供。原 int1 不会被复制为 int2。新增网络读取真实 pb1 与原 int0；门输出只进入 bit2 的表达链，保留成熟、游离池结合/解离和 DNA 动力学。

## 文件

- `hybrid_model.py`：发送端适配、明确参数、17维新模块及27维连接。
- `diagnostics.py`：预先定义的探索性读窗与状态健康检查。
- `run_initial.py`：独立低两位与混合模型比较、原默认RK45结果存档、数据和图输出。
- `test_hybrid.py`：与冻结51态模块的逐RHS比较、初态、质量收支、分钟/小时积分和无反馈检查。

不依赖导入有顶层副作用的曾脚本，不全局修改 ZENG。状态均显式命名；S0=1-pb0、S1=1-pb1、S2=b2_S。

## 运行

在本目录打开 PowerShell。使用项目 Python，不要用裸 python：

```powershell
& 'D:\aconade\python.exe' -B .\test_hybrid.py
& 'D:\aconade\python.exe' -B .\run_initial.py --hours 1
& 'D:\aconade\python.exe' -B .\run_initial.py
```

默认计数时长沿用原脚本2000min（33.333h），每分钟采样，DOP853 rtol=2e-7/atol=2e-9/max_step=1min。另保存同一输入下原默认RK45的2000点输出。上游默认仍为原BDF容差，不能称整个求解链已通过严格容差验证。

`--upstream-mode tight` 是明确的新数值对照：BDF rtol=1e-9/atol=1e-11，并重新计算归一化分母，不能悄悄替换原输入。`--n-gate` 与 `--clock-scale` 都会记录在参数文件；尚未进行参数搜索。

上游保留0–3000min的原采样与归一化，超出50h强制报错，防止插值端点被静默延长成常数输入。

每次运行写入新的 `results/时间戳/`，不会覆盖旧结果；保存：完整27态与发送端轨迹NPZ/CSV、原上游和原RK45轨迹、参数与初态、源哈希、环境、读窗和穿越事件、状态健康、低十维差、PNG/PDF图、独立哈希清单。

## 基线假设与不能声称的事

1. n_A1_gate=6，F1产生指数=4；clock_K=.3、clock_n=2。未使用51态默认构造的.4/3。
2. clock_scale=1 是新接口的未标定假设；她的a.u.与我们时钟阈值的a.u.尚无共同物理定标。uM_per_au=5.75仅记录接收端历史标尺，不赋予曾模型全部变量同一µM单位。
3. 新carry成熟32.5min，bit2成熟20min；两者不能混用。下游不额外加生长稀释，不能解释成细胞不生长。
4. 初态沿用她的低两位预平衡；新carry按PB1=1预平衡，bit2从PB开始、Rep预平衡。没有保证混合模型一定成功。
5. 读窗使用原Int0峰间谷、总宽20%、0.3/0.7带、80%占据，峰突出度取本次全程范围10%，属于新模型的探索性读法，未移动相位寻优。
6. 当前仅输出数字序列、阈值穿越、低位一致性和健康。**尚未实现正式carry配对、setup/hold与配对泄漏；不输出继承自51态的certified=True。** 短时有序序列也不等于长期三级认证。
7. 波形发生器、归一化输入和接收端方程不同，旧600h结果不转授本模型。图标题固定标为preliminary/not certified。
