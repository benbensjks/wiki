### 可直接使用的简短图注

**M-6**：韩亚轩上游驱动的HBY–ZMH–HBY三级模型，300 h内共有27个读窗；丢弃前8窗后，19个稳态读数按模8递增。bit0回零→第一级门→bit1翻转为14/14/14，bit1回零→第二级门→bit2翻转为7/7/7。本图为指定参数下的确定性模型结果。

**M-21**：在HZH标称工作点，移除Int0时钟因子后，300 h模8读出及两级事件对应仍成立；进位门输出增强，bit2最小读窗带边距离由0.2821降至0.1857。图中“读数不变”仅指数字标签和commitment，不指连续状态或抗扰性。

**M-22**：比较保留时钟门、移除时钟门、以及移除后将完整模8周期内Int2源总积分配平的三臂。三臂都保持标称模8；最小bit2带边距离依次为0.2821、0.1857、0.2524。配平恢复了部分落态深度，剩余差异与输入时间分布相容；不能把69%／31%的差额直接解释成两个可加的生化因果效应。

**M-28**：同一对照的**合版**（bit0／bit1／bit2 三条状态曲线放在同一格，颜色区分位）。**每臂单独一张**（`fig_M21_pair_kept` / `fig_M21_pair_removed`，各 3 行：Int0 翻译 / 三个 bit 状态 / 解码值），再把两臂**左右拼合**成 `fig_M21_pair_combined`。取窗为**一个完整模 8 周期**：稳态读窗 7–14 = 进位周期 15–22 = **161.9–246.7 h（84.7 h，8 个读窗）**，解码值依次 **0,1,2,3,4,5,6,7**，且包含无门臂带边距最低的那一段（周期 21–22）。两列 **y 轴刻度严格相同**，因此可以直接左右对读：bit0／bit1 两列逐位重合（max|Δ| = 0，脚本内断言），只有 bit2 的落态更浅（最小带边距 0.2821 → 0.1857）。
> **为什么阶梯（解码值）两列看起来一样**：读数只在每个谷值窗量化一次，判据是固定阈值 0.30/0.70 加 ≥80% 占用率；两臂连续轨迹 bit2 最大差 **0.2305**，但每窗都落在同一侧，所以**标签序列相同、余量不同**。答问时不要说成"两组没差别"。

**M-27**：同一三臂的 **Bit 状态**视角（Bit 0 = `b0_S`、Bit 1 = 1 − `pb1_zmh`、Bit 2 = `b2_S`）。bit0 与 bit1 的读窗状态在三臂中**逐位相同**（max|Δ| = 0，脚本内断言，不成立即中止），只有 bit2 响应：`S2` 最大偏离 保留→移除 **0.230548**、保留→配平 **0.042719**（降 81.5%）。该图与 M-22 的带边距离口径（−34.2% → −10.5%）方向一致但**量不同名**：一个量是轨迹最大偏离、一个是稳态带边距离，**不可互相换算引用**。

> **取窗说明（三版同源）**：一个"**进位周期**"在这里定义为**一次 bit1→bit2 进位** = **2 个时钟读窗 ≈ 21 h**（读窗周期实测 10.50 h），即所画现象的固有周期。取窗锚点自动落在稳态中 removed 臂带边距**最低**的那一段（`cycle 22`，t₀ = 235.97 h，该处 0.1857），使对比在画框内最大。三版：**1 周期 = 235.97–256.97 h**、1.5 周期 = 235.97–267.47 h、全 300 h。若需要的是**时钟读窗周期（10.5 h）**而非进位周期，参数改一个常量即可另出。

**M-11**：混合模型参数扰动的离散格点结果。颜色只代表图注注明的计数、事件或完整判据；格点之间的连续可行区尚未证明。

**M-26**：HBY–ZMH–HBY（HZH，34态）**已认证 300 h 轨迹**的一段，取窗 **97.0–139.4 h（42.4 h ＝ 一个完整第二级进位周期）**，由保存轨迹与认证事件表绘制，**无重积分**。同一时间轴上，上半为第一级进位（PB0 → A0／F0 → g0 → Int1），下半为第二级（PB1 → A1／F1 → g1 → Int2）；竖线标出 bit0 LR→PB、进位门开启、bit1 LR→PB 与 bit2 翻转，其中 **bit1 LR→PB 贯穿全部八行**，因为它同时是第一级的输出与第二级的输入。两点读数：其一，**Δt(A→F)**（激活越过半峰到抑制越过半峰）第一级 **0.950 h**、第二级 **1.467 h，长 54%** —— 两级分别用 ZMH 约化直接蛋白方程与 HBY 含 mRNA→成熟链的表达，这是两种末级结构差异的直接可视证据；其二，窗内**两次低位进位只有一次传播到 bit2**：第二次 g0 开启时 bit1 已是 PB（S1 ＝ 0.0143），须再正向前进一次才能反向，故下一次 bit1 LR→PB 要等到 159.6 h，这正是第二级节律恰为第一级一半的原因（第一级 14 次／300 h，第二级 7 次／300 h）。
> **方向约定（易错）**：S0 ＝ `b0_S`、S1 ＝ 1 − `pb1_zmh` 都是 **LR 占比**，一次进位是该信号**向下**穿越 0.5；认证表的 `flip_h` 记录**每一次**穿越（上下交替），只有 `flip_direction == "down"` 的行才是进位。窗口内的铰链时刻有三个独立来源互证：S1 下降沿 117.271、认证表 down 行 117.271、`bit1_to_bit2[].reverse_peak_h` 117.200。
> **刻度约定**：g0／g1 共用 [0, 0.68]、Int1／Int2 共用 [0, 3.05]，使两级可直接对读（窗内实际峰 g0 0.629／g1 0.387，Int1 2.716／Int2 2.758）；A／F 曲线按各自窗内最大值归一化（A0 峰 1.905 对 F0 峰 6.422，A1 1.360 对 F1 2.360），**绝对值写在该行图例的斜杠后**。
> **脚本内断言**：保存轨迹重分析必须复现 `certified_v1`、19 个稳态读窗与认证码串；窗口必须恰好含 2 次低位进位、1 次高位进位与 1 次 bit2 翻转；两次 g0 开启时 bit1 必须分别为 LR 与 PB；渲染后文字越界数必须为 0。任一不成立即中止。

## 当前不能引用的旧图与常见误读

- [HZZ旧机制图 fig3_mechanism](hby_zmh_zmh/failure_attribution/figures/fig3_mechanism.png) 用两个不同时刻的 Int2、RDF2峰值相乘；用 [v2同刻统计](hby_zmh_zmh/failure_attribution/figures/fig3_mechanism_v2.png) 替代。v2显示乘积峰值本身也不能单独判定成功。
- [HZZ旧八相位图](hby_zmh_zmh/failure_attribution/figures/fig4_eight_phases.png) 与 [旧phase事件图](hby_zmh_zmh/failure_attribution/figures/fig6_phase_events.png) 来自错误初态构造；仅用M-24的八数字初态v2。
- [HZZ的旁路图](hby_zmh_zmh/failure_attribution/figures/fig5_bypass.png) 与M-21属于不同末级和门律。它能作替代模型的补充图，不能替代HZH的有门／无门比较。
- `GATE_MIN_DOSE_H=0.02 h` 是事件识别门槛，不能称为DNA写入的生化阈值。计数失败与事件阈值失配需分开报告。
- M-21三臂图中“总输入配平”只在相同完整模8时间区间成立；源积分相等不保证成熟Int2波形或落态相等。
- 位内T/Rep、振荡器TetR和进位抑制臂F是不同角色；中位的RDF1与carry0的F0也不是同一池。
- **M-26 的竖线只有 `flip_direction == "down"` 的穿越才是进位**；认证表 `flip_h` 同时记录向上的穿越（PB→LR），把它们一并当成进位会让同一个窗口出现两条"铰链"线。用 `bit1_to_bit2[].reverse_peak_h` 交叉校验即可避免。（第一版脚本正是这样错的。）

## 图件入Wiki前的简单检查

1. 每张图注写明模型名、参数版本、输入、时长与判据范围。HZH、HZZ、独立51态和twobit34不得只统称“34态”或“三比特”。
2. 数据图确认PNG/SVG/PDF的标题、轴标签、图例、角落注释均未裁切；M-21两张图的长标题与底部文字需重点检查，M-23/M-24的标题也应缩短。
3. 主文最多放一张机制总览、一张主结果、一张参数工作区和一张消融／配平对照；其余进补充，避免重复讲同一个码串。
4. 发布前按图所在目录的provenance或结果JSON核对来源与哈希。图片更新后重新计算哈希，不从这份说明复制可能过期的旧摘要值。

当前判断：M-6、M-11、M-21、M-22、**M-26**的数据和来源可定位；M-25尚无成图；M-18有完整扫描数据但缺图。M-2和M-4共同说明接线，不能各自叫完整三级图。
