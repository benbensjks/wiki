# HBY–ZMH–ZMH 初步对照

架构：HBY bit0（11态）→《完整二级级联.py》现行 A0/F0＋bit1（6态）→《前馈三级级联.py》探索性 A1/F1＋bit2（6态）。韩上游单独求解，总接收状态数23。

`model_hzz.py` 复用现有低两位方法，新增6态尾部；负自馈只作用于A1产生项。开启/关闭使用各自自洽初值，clock保留新三级代码的0.4/3并读取HBY bit0 Int0。原文件不直接导入执行，用AST读取参数和参考RHS作对照。

运行：`D:\aconade\python.exe -B run_comparison.py`。默认300 h、1 min输出、DOP853，先复现HZH参考，再跑负自馈off/on。结果自动写入本目录的`results/时间戳/`，包括PNG/SVG/PDF图、完整轨迹、分项判据、参数、源文件哈希和中文说明。

新ZMH三级参数属于探索版，与现行二级参数分开使用；该实验不是三种正交酶的实测参数模拟。模型不自动调参求成功。两组新模型均需独立验收，已有认证不会转授。

首轮输出：`results/20260930_201845/`。两组均未形成模8，前两位正常，bit2仅穿越0.5一次并停留高带。具体码串、状态范围与门事件阈值的区别见该目录`结果说明.md`和`诊断补充.md`。

`analyse_saved.py <结果目录>`从已保存轨迹生成脉冲放大图及补充诊断，无需重新积分。`parameters.json`中末级参数保留了来源文件的完整字典；真正调用的末级键另列于`analysis_metadata.json`，未调用的原低位参数不会覆盖现行中间模块。
